# 오늘의 모먼트 프론트엔드 시연 시나리오

로그인 화면이 있다는 가정 아래, **기록·카드·공유·통계**를 네 축으로 약 5분 동안 시연한다. 발표자는 실제 기록 저장을 먼저 보여준 뒤, 기존 시연 모드의 합성 데이터로 카드 공개 → SNS 공유 → 감정 통계를 보여준다. 도감은 카드 보관 방식을 설명하는 보조 기능으로 짧게 포함한다.

- 작성 기준: 2026-11-24 프론트엔드(`38fbebb`, 카드 등급 시각화·건너뛰기·분석 대기 안내·접근성·데이터 안전·화면 다듬기 반영)
- 대상: 프로젝트 발표 및 기능 시연
- 핵심 메시지: 하루를 기록하고, 카드로 만나는 감정을 SNS로 나누며, 쌓인 기록은 통계로 돌아본다.
- 로그인 전제: 로그인 화면과 성공 후 기록 화면으로 이동하는 동작이 준비되어 있다고 가정한다. 인증 구현은 이 문서의 작업 범위에 포함하지 않는다.

## 1. 시연에서 구분할 동작

| 구분 | 시연 내용 | 설명 기준 |
| --- | --- | --- |
| 가정한 기능 | 로그인 화면에서 시연용 계정으로 진입 | 로그인 방식과 버튼 이름은 준비된 화면에 맞춘다. 계정 간 데이터 분리나 서버 동기화까지 구현되었다고 설명하지 않는다. |
| 현재 실제 동작 | 일기 작성·저장, 최근 기록 및 카드 달력 확인 | 기록은 현재 브라우저의 IndexedDB에 저장된다. 실제 기록의 감정 분석은 연결 전이므로 저장 후 ‘분석 대기’로 표시된다. |
| 현재 시연 모드 | 분석된 카드 공개, 도감 보관 방식, SNS 공유, 감정 통계 | 합성 예시 데이터를 사용한다. 방금 입력한 글의 실시간 AI 분석 결과라고 소개하지 않는다. |

## 2. 발표 전 준비

1. 개인 일기가 없는 시연 전용 브라우저 프로필을 준비한다. 시작할 때 시연 모드는 끄고, 당일 기록이 없는 상태인지 확인한다. 저장 버튼이 ‘기록하고 카드 받기’(모바일 ‘카드 받기’)이면 당일 기록이 없는 상태다. 실제 기록은 하루 한 편이므로, 당일 기록이 있으면 버튼이 ‘수정한 내용 저장하기’ 또는 ‘오늘 기록 바꾸기’로 바뀌고 바꾸기는 확인창을 띄운다. 반복 시연 때에는 별도 시연 프로필을 쓰거나 프로필의 ‘모든 기록 삭제’로 시연 프로필만 비운다.
2. 가정한 로그인 화면에서 기록 화면으로 넘어가는 경로를 준비한다. 로그인 화면이 아직 없다면 로그인 시안이나 슬라이드를 보여준 뒤 프론트엔드로 전환한다고 사전에 알린다.
3. 발표 화면 크기와 테마를 고정하고, 글자가 잘 보이는지 확인한다. 시연 중 테마 변경은 생략한다.
4. 아래 예시 글을 준비하고, 입력 시간을 줄이려면 붙여넣기를 사용한다.
5. 프로필의 ‘시연 모드’를 켜면 카드 획득 팝업이 뜬 뒤 예시 기록 목록으로 이동하는지 확인한다. 분석이 끝난 예시 기록 한 편과 통계를 보여줄 월을 미리 골라 둔다. 목록 첫 페이지 위쪽의 분석 완료 예시는 1단계(‘은은한 빛’)이고, 2·3단계 예시는 목록 뒤쪽 페이지에 있다. 등급 효과를 강조하려면 3단계(‘홀로그램 포일’) 예시를 골라 위치를 기억해 둔다.
6. 예시 카드 공개 연출을 한 번 확인하고, 본 시연 전에는 실제 모드로 되돌린 뒤 새로고침한다. 같은 예시 카드를 이미 열어 본 상태라면 공개 연출이 다시 나오지 않을 수 있으므로 리허설 후 초기 상태를 확인한다. 연출 중 보이는 ‘건너뛰기’ 버튼은 본 시연에서 누르지 않는다.
7. 발표 기기의 OS ‘동작 줄이기’(움직임 줄이기) 설정을 끈다. 켜져 있으면 공개 연출이 흔들림·입자 없이 페이드로만 진행되고 “기기 설정에 맞춰 움직임을 줄여 보여드려요” 안내가 붙는다.
8. 자정 직전에는 리허설하지 않는다. 자정을 넘기면 편집기가 새 날짜로 옮겨지고, 저장 버튼의 첫 누름은 날짜 변경 안내만 보여준다.
9. 예시 카드의 공유 미리보기, 일반 PNG와 스토리 PNG 생성이 동작하는지 확인한다. SNS 전달 흐름을 보여주기 위해 가능하면 파일 공유를 지원하고 SNS 앱이 설치된 모바일을 발표 환경으로 준비한다. 기기 공유를 지원하지 않으면 스토리 이미지를 저장하는 대체 흐름을 준비한다.
10. 내려받은 이미지와 주요 화면 캡처는 예비 자료로 준비한다. 공개 게시가 필요한 행사는 별도 시연용 계정과 합성 예시만 사용하고, 기본 시연은 공유 창 또는 이미지 저장 확인까지 진행한다.

### 입력할 예시 글

> 오늘 팀 프로젝트 발표 준비를 마쳤다. 처음에는 긴장했지만 팀원들과 함께 정리하니 마음이 한결 가벼워졌다. 서로 부족한 부분을 채워 준 덕분에 뿌듯했고, 도와준 팀원들에게 고마웠다.

이 글은 저장 동작을 보여주기 위한 입력이다. 특정 감정이나 등급의 카드가 나온다고 예고하지 않는다.

## 4. 단계별 조작과 발표 멘트

### 단계 1 로그인과 서비스 소개

**조작:** 준비된 로그인 화면에서 시연용 계정으로 진입하고 기록 화면을 연다. 로그인 시안을 사용하는 경우에는 성공 후 화면을 전환하는 흐름임을 밝힌다.

**발표 멘트**

> “오늘의 모먼트는 하루를 기록하고, 감정 카드를 만들고, SNS로 공유하며, 통계로 돌아보는 서비스입니다. 로그인 화면이 준비되어 있다는 가정으로 사용자 흐름을 보여드리겠습니다.”

**확인할 화면:** 기록·통계·도감 탭과 일기 작성 영역. 모바일에서는 하단의 세 탭을 짚어 준다.

### 단계 2 오늘의 기록 작성과 저장

**조작:** 기록 탭에서 예시 글을 입력하고 ‘기록하고 카드 받기’를 누른다. 모바일의 버튼 이름은 ‘카드 받기’다. 저장 후 카드 화면으로 넘어가 ‘기록은 잘 저장됐어요’ 제목과 진행 칩 ‘저장 ✓ · 감정 읽기 대기 · 카드 공개’가 표시되는지 확인한다. ‘감정 읽기 대기’ 칩은 깜빡이지 않는 정지 표시다.

**발표 멘트**

> “오늘 있었던 일을 자유롭게 적습니다. 사용자가 감정을 직접 고르는 대신, 글을 남기는 데 집중하도록 구성했습니다. 기록은 하루 한 편씩 남길 수 있습니다. 저장 버튼을 누르면 기록이 보관됩니다.”

**확인할 화면:** 저장 후 분석 대기 패널. 현재 버전에서는 이 단계에서 분석 완료 카드가 자동으로 나오지 않는다. 기록 화면 아래의 “이 브라우저에만 보관돼요 · 브라우저 데이터를 지우면 함께 사라져요” 안내는 저장 위치 질문이 나올 때 짚을 수 있다.

### 단계 3 시연 모드 전환 안내

**조작:** ‘기록으로 돌아가기’를 누르고, 상단 아바타로 프로필을 연다. ‘시연 모드’를 켜면 카드 획득 팝업이 뜨므로 ‘닫기’를 누르고 예시 기록 목록으로 이동한다.

**대안 경로(설명을 화면에 맡길 때):** 분석 대기 패널의 ‘도감 보기’를 누르면 도감이 “카드가 분석을 기다리고 있어요 · 기록 1편은 잘 저장됐어요”라고 현재 상태를 보여준다. 여기서 ‘시연 모드로 미리 보기’를 누르면 도감에 머문 채 예시 도감으로 바뀐다. 이 경로를 쓰면 단계 4는 도감의 카드 → 카드 상세 → ‘이 카드가 담긴 기록’에서 예시 기록을 열어 시작한다. 통계 탭도 분석된 기록이 없으면 같은 ‘분석 대기’ 배너와 버튼을 보여준다.

**발표 멘트**

> “방금 작성한 기록은 실제로 저장됐습니다. 현재 프론트에는 새 감정 분류 모델이 연결되기 전이라 실제 글은 분석 대기로 표시됩니다. 이어서 보실 카드와 통계는 시연 모드에 준비된 합성 예시입니다.”

**확인할 화면:** 시연 모드 표시와 예시 기록 목록. 방금 작성한 글과 합성 예시를 구분해 소개한다.

### 단계 4 감정 카드 공개와 보관

**조작:** 미리 골라 둔 분석 완료 예시 기록을 연다. 자동 공개 연출(두근두근 1.5초 → 고조 1.2초 → 펑 1.7초)이 끝날 때까지 기다린다. 펑이 시작되면 안내 제목이 “1단계 · 은은한 빛 카드예요”처럼 바뀌고, 결과 화면에서 카드의 감정 이름과 단계를 보여준다. ‘도감에서 보기’를 눌러 해당 카드 상세에서 연결 기록과 보관 방식을 짧게 소개한다. 카드는 저장될 때 자동으로 도감에 담기며, 이 버튼은 담긴 위치를 열어 준다.

연출 중 안내 영역의 ‘건너뛰기’는 기본 시연에서 누르지 않는다. 시간이 부족할 때만 누르며, 첫 누름은 기다림만 건너뛰고 등급별 펑 효과는 그대로 재생한다. 버튼이 ‘바로 보기’로 바뀐 뒤 다시 누르거나 Esc를 누르면 결과 화면으로 바로 간다.

**발표 멘트**

> “분석이 완료된 기록은 이런 카드로 확인할 수 있습니다. 색은 감정을, 테두리와 빛 효과는 단계를 나타냅니다. 카드는 도감에 자동으로 담겨 관련 기록과 함께 다시 볼 수 있습니다. 이어서 이 카드를 SNS로 공유해 보겠습니다.”

**확인할 화면:** 공개된 카드, 감정 이름과 단계, 도감의 해당 카드 상세. 도감은 대분류 3개·소분류 9개·단계 3개로 총 27칸이며 전체 탐색은 생략한다. 이미 채워진 예시 도감이므로 새 수집 수가 증가했다고 설명하지 않는다.

등급 효과는 색이 아니라 모양과 재질로도 구분된다. 정지 화면에서도 차이가 보이므로 질문이 나오면 아래 표로 설명한다.

| 등급 | 보이는 효과 | 움직임 |
| --- | --- | --- |
| 빈 카드 | 점선 테두리, 안쪽이 움푹한 빈 슬롯 | 없음 |
| 1단계 · 은은한 빛 | 광채, 안쪽 흰 하이라이트, 위쪽 반광 | 천천히 숨 쉬듯 밝아짐 |
| 2단계 · 금속 이중 링 | 얇은 안쪽 링과 넓은 바깥 링, 금속 결 프레임, 모서리 꺾쇠 | 두 빛이 반대 방향으로 흐름 |
| 3단계 · 홀로그램 포일 | 굵은 홀로그램 링, 넓은 바깥 발광, 꺾쇠와 반짝임, 표면 프리즘 반사광 | 색 순환, 반사광이 포인터·기울기를 따라감 |

확률에 관한 질문을 받으면 “모델이 해당 분류를 선택한 확률이며, 감정의 강도나 모델 전체 정확도를 뜻하지 않습니다”라고 설명한다. 단계와 등급 효과도 구분하고, 높은 등급을 감정이 더 좋거나 건강하다는 의미로 소개하지 않는다.

### 단계 5 SNS 공유와 공개 범위 선택

**조작:** 해당 예시 카드의 도감 상세에서 ‘공유하기’를 누른다. 아래 순서로 75초 안에 진행한다.

1. 공유 미리보기에서 ‘기록 문장 넣기’를 껐다 켜고, ‘분석 확률 표시’가 꺼져 있는지(기본값) 확인한다.
2. ‘이미지로 저장’을 눌러 내려받은 1080×1350 PNG를 보여준다.
3. ‘인스타그램 스토리로 공유’를 누른다. 파일 공유를 지원하는 기기에서는 공유 창과 SNS 앱 선택 흐름을 보여준다. 미지원 환경에서는 저장된 1080×1920 스토리 이미지를 보여주고 SNS에서 업로드하는 흐름을 설명한다.
4. 공개 게시 없이 공유 창이나 이미지 확인을 마친 뒤 앱으로 돌아와 공유 화면을 닫는다.

**발표 멘트**

> “공유는 핵심 기능 중 하나입니다. 기록 전체 대신 감정 카드를 SNS에 나눌 수 있고, 첫 문장을 넣을지도 직접 선택합니다. 일반 이미지뿐 아니라 스토리에 맞는 세로 이미지도 제공하며, 지원 기기는 공유 창으로 전달합니다. 분석 수치는 기본적으로 숨겨집니다.”

**확인할 화면:** 인용 옵션에 따라 달라지는 미리보기, 일반 PNG, 기기 공유 창 또는 스토리 PNG. 인용은 기본 첫 문장 최대 40자이며, 그 밖의 일기 본문은 이미지에 포함되지 않는다. 인용이 이미지 칸보다 길면 띄어쓰기에서 줄이 바뀌고 마지막 줄은 “…”으로 줄어들되 닫는 따옴표는 남는다. ‘앱 주소 복사’ 버튼은 앱 주소만 복사하며 받는 사람에게 카드나 기록이 보이지 않으므로 기본 시연에서 누르지 않는다.

스토리 공유는 기본 시연에 포함한다. 공유 창의 SNS 목록은 설치된 앱과 기기 지원에 따라 다르며, 인스타그램에 자동 게시되는 기능으로 설명하지 않는다.

### 단계 6 통계로 감정 흐름 돌아보기

**조작:** 통계 탭을 누르고, 리허설에서 골라 둔 예시 기록이 있는 월로 이동한다. 진입 연출이 끝나면 요약 카드, 긍정 추이, 감정 분포, 감정 달력을 차례로 짚는다. 시간 여유가 있으면 요일별 마음을 보여준다.

**발표 멘트**

> “기록과 카드를 쌓은 뒤에는 통계로 감정 흐름을 돌아볼 수 있습니다. 한 달의 기록 수와 감정 분포를 보고, 긍정 추이와 달력으로 시기별 변화를 살펴봅니다. 이 화면은 예시 기록을 기준으로 보여드리고 있습니다.”

**확인할 화면:** 선택한 월과 그래프. 추이는 긍정 비율의 3일 이동평균이며, 심리 진단이나 미래 감정 예측으로 설명하지 않는다.

### 단계 7 기록 화면으로 돌아와 마무리

**조작:** 기록 탭으로 돌아와 최근 기록과 카드 달력을 보여주며 마친다. 이때 화면은 계속 시연 모드임을 유지한다.

**발표 멘트**

> “기록하고, 카드로 만나고, SNS로 공유하고, 통계로 돌아봅니다. 실제 저장은 현재 동작하며 카드·공유·통계는 합성 예시로 보여드렸습니다. 다음 단계는 실제 감정 모델 연결입니다.”

| 상황 | 대응 |
| --- | --- |
| 로그인 화면이 준비되지 않음 | 로그인 시안 또는 슬라이드에서 진입 가정을 설명하고, 준비된 프론트의 기록 화면으로 전환한다. 실제 인증 성공이라고 설명하지 않는다. |
| 오늘 기록이 이미 있음 | 기록 화면의 ‘수정하기’로 당일 기록을 고쳐 ‘수정한 내용 저장하기’로 저장한다. 새 글을 쓰면 버튼이 ‘오늘 기록 바꾸기’로 바뀌고 확인창이 뜨므로, 기존 기록을 지워도 되는 시연 프로필일 때만 ‘바꿔서 저장’을 누른다. 발표 중 개인 기록 전체를 지우지 않는다. |
| 저장을 눌렀는데 “날짜가 바뀌었어요” 안내만 나옴 | 자정을 넘긴 상태다. 안내대로 글이 새 날짜 기록으로 저장된다는 점을 확인하고 한 번 더 누른다. |
| 저장 실패 안내가 나옴 | 입력 내용이 남아 있는지 확인하고 ‘다시 시도’를 누른다. 계속 실패하면 저장 실패 상태라고 밝히고, 실제 저장 성공을 주장하지 않은 채 시연 모드의 나머지 화면으로 넘어간다. |
| 카드가 분석 대기로만 보임 | 실제 기록에서는 정상적인 현재 상태다. 프로필의 시연 모드를 켜고 분석 완료 예시를 연다. |
| 시연 모드를 켜자 카드 획득 팝업이 뜸 | 정상 동작이다. ‘닫기’를 누르고 예시 기록 목록으로 진행한다. ‘내 감정 도감 보기’를 누르면 도감으로 가므로 대안 경로로 이어 간다. |
| 예시 카드 공개 연출이 다시 나오지 않음 | 이미 열어 본 예시인지 확인한다. 다른 분석 완료 예시를 열거나, 시연 전 새로고침 후 시연 모드에 다시 진입한다. |
| 실수로 ‘건너뛰기’를 누름 | 펑 효과와 결과는 그대로 나온다. 다시 누르지 말고 결과 화면이 뜨면 이어서 진행한다. |
| 공개 연출에 흔들림·입자가 없고 “움직임을 줄여 보여드려요” 안내가 나옴 | 발표 기기의 OS 동작 줄이기 설정이 켜진 상태다. 등급은 정지 효과로 구분되므로 그대로 진행하고, 다음 리허설 전에 설정을 끈다. |
| 통계가 비어 있음 | 시연 모드인지 확인하고 예시 기록이 있는 월로 이동한다. 실제 모드에서는 ‘분석 대기’ 배너가 이유를 설명하며, 배너의 ‘시연 모드로 미리 보기’로 바로 전환할 수 있다. |
| 다운로드가 차단됨 | 공유 미리보기와 리허설에서 저장한 예시 PNG를 보여준다. 내려받지 못한 상태를 성공으로 소개하지 않는다. |
| 기기 공유 창에 원하는 SNS가 없거나 파일 공유를 지원하지 않음 | 스토리 PNG를 저장해 보여주고, 해당 SNS에서 이미지를 선택해 게시하는 흐름을 설명한다. 자동 전송이나 게시가 완료됐다고 설명하지 않는다. |
| 발표 시간이 부족함 | 로그인 소개와 도감 상세, 일반 PNG 파일 열기를 줄인다. 실제 기록 저장 → 예시 카드 → SNS 공유 창 또는 스토리 이미지 → 통계 요약의 네 축은 유지한다. |

## 6. 예상 질문과 답변

**방금 입력한 글을 AI가 분석한 것인가요?**

현재 실제 글은 저장 후 분석 대기로 표시됩니다. 카드 공개와 통계는 합성 예시 데이터로 시연하며, 실제 분석 연결은 후속 작업입니다.

**로그인하면 다른 기기에서도 같은 기록을 볼 수 있나요?**

이 시나리오에서는 로그인 화면만 가정했습니다. 현재 프론트의 기록은 브라우저별로 저장되므로 계정 기반 동기화는 별도 구현이 필요합니다.

**카드 확률이 높으면 더 강한 감정인가요?**

확률은 해당 감정 분류에 대한 모델의 선택 확률입니다. 감정 강도나 서비스 전체의 정확도를 의미하지 않습니다.

**일기 전체가 공유되나요?**

공유 이미지에는 카드와 선택한 정보가 들어갑니다. 인용은 기본적으로 첫 문장 최대 40자이며 끌 수 있고, 나머지 본문은 이미지에 포함되지 않습니다. 분석 확률도 기본으로 넣지 않습니다.

**카드 단계마다 무엇이 다른가요?**

단계가 높을수록 효과가 테두리에서 프레임, 카드 표면과 바깥으로 넓어집니다. 빈 카드는 점선, 1단계는 은은한 빛, 2단계는 금속 이중 링과 모서리 장식, 3단계는 홀로그램 포일입니다. 색만으로 구분하지 않아 작은 카드에서도 단계를 알아볼 수 있습니다.

**공개 연출을 매번 기다려야 하나요?**

‘건너뛰기’로 기다림을 건너뛸 수 있고, 한 번 더 누르면 결과로 바로 갑니다. 기기에서 동작 줄이기를 켠 사용자에게는 흔들림·깜빡임 없이 같은 순서를 조용한 화면으로 보여줍니다.

**다른 글로 오늘 기록을 덮어쓸 수 있나요?**

하루 한 편이므로 다른 초안으로 저장하면 기존 기록이 바뀝니다. 이때 버튼 이름이 ‘오늘 기록 바꾸기’로 바뀌고, 되돌릴 수 없다는 확인창을 거칩니다.

## 8. 데스크톱과 모바일 시연 영상

영상판은 로그인 장면을 생략하고 기록 화면부터 시작한다. 자막·음성·배경음·기기 장식 없이 기록 → 카드 → SNS 이미지 공유 → 통계를 각 5분 동안 보여준다. 첫 75초에 기록 입력·저장·분석 대기를 담고, 이후 시간 배정은 위 진행표와 같다.

| 파일 | 브라우저 콘텐츠 영역 | 녹화 해상도 |
| --- | --- | --- |
| `desktop.mp4` | 1920×1080 | 1920×1080 |
| `galaxy-s24.mp4` | 360×780 | 720×1560 |
| `iphone-17-pro.mp4` | 402×874 | 804×1748 |

모두 Chrome 기반이다. 모바일은 화면 크기와 터치 레이아웃의 재현이며 실제 삼성 인터넷·iOS Safari·휴대폰 키보드·SNS 공유 창 촬영이 아니다. SNS 장면에서는 일반 PNG와 스토리 PNG를 실제 생성·저장한 뒤 브라우저에서 결과를 보여준다. 실제 SNS 게시나 가짜 공유 창은 포함하지 않는다.

루트에서 다음과 같이 실행한다. Playwright는 기존 브라우저 테스트와 같은 `CARDEX_PLAYWRIGHT`·`CARDEX_CHROMIUM` 설정을 사용하며, 해당 버전의 Playwright FFmpeg도 필요하다. `CARDEX_FFMPEG`에는 MP4 변환용 `libx264` 지원 FFmpeg 실행 파일 경로를 지정한다. 미지정 시 임시 경로 `moment-video-tools/imageio_ffmpeg/binaries`를 확인한다.

```powershell
node frontend/tools/record-demo.cjs --rehearsal
node frontend/tools/record-demo.cjs
node frontend/tools/record-demo.cjs --device galaxy
```

`--device`는 `all`(기본), `desktop`, `galaxy`, `iphone` 중 하나다. `--rehearsal`은 버전당 45초로 사전 검증하고, 본 녹화는 버전당 300초다. `--out <경로>`로 새 출력 경로를 지정할 수 있다. 기본 출력은 Git에서 제외되는 `artifacts/demo-videos/<실행시각>/`이며 기존 경로를 지정하면 덮어쓰지 않고 중단한다. 원본 WebM, 장면별 PNG, 공유 이미지, 검증 JSON도 보관한다. 녹화 브라우저에서는 Web Share 기능을 꺼 앱이 제공하는 실제 스토리 이미지 다운로드 경로를 사용한다.

녹화는 별도 브라우저 저장소에서 합성 시연 글과 동일한 예시 카드를 사용한다. 생성된 MP4는 전체 디코딩 검사를 거치며, 주요 장면의 가로 넘침·실제 저장·PNG 크기·브라우저 오류도 검사한다. 최종 전달 전 영상 길이와 주요 프레임을 추가 확인한다.

영상의 장면 순서는 위 진행표와 같으며, 스크립트는 프로필 경로로 시연 모드를 켜고 카드 획득 팝업을 닫는다. 예시 카드는 목록 첫 분석 완료 예시(1단계)를 열고, 공개 연출은 ‘건너뛰기’ 없이 끝까지 녹화한다.

### 영상에서 알려진 차이

- 1920×1080 데스크톱에서는 분석 대기 패널의 ‘기록은 잘 저장됐어요’ 제목이 카드 아래에 있어 `02-saved-pending` 장면 첫 화면에는 진행 칩과 카드만 보인다. 실제 발표에서는 조금 내려 제목과 안내를 보여준다.
- 모바일 녹화는 스크립트가 마우스 방식 클릭을 써서 포일 안내가 “카드 위에서 마우스를 움직이면…”으로 보인다. 실제 휴대폰에서는 터치 안내(“카드를 터치하고 움직이면…”)가 나온다.

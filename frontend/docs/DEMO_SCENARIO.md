# 오늘의 모먼트 프론트엔드 시연 시나리오

로그인 화면이 있다는 가정 아래, 하루를 기록하고 감정 카드로 돌아보는 과정을 약 5분 동안 시연한다. 발표자는 실제 기록 저장을 먼저 보여준 뒤, 기존 시연 모드의 합성 데이터로 카드 공개와 도감·통계·공유 경험을 설명한다.

- 작성 기준: 2026-11-23 프론트엔드
- 대상: 프로젝트 발표 및 기능 시연
- 핵심 메시지: 하루의 기록이 카드로 쌓이고, 쌓인 기록을 통해 자신의 감정 흐름을 돌아본다.
- 로그인 전제: 로그인 화면과 성공 후 기록 화면으로 이동하는 동작이 준비되어 있다고 가정한다. 인증 구현은 이 문서의 작업 범위에 포함하지 않는다.

## 1. 시연에서 구분할 동작

| 구분 | 시연 내용 | 설명 기준 |
| --- | --- | --- |
| 가정한 기능 | 로그인 화면에서 시연용 계정으로 진입 | 로그인 방식과 버튼 이름은 준비된 화면에 맞춘다. 계정 간 데이터 분리나 서버 동기화까지 구현되었다고 설명하지 않는다. |
| 현재 실제 동작 | 일기 작성·저장, 최근 기록 및 카드 달력 확인 | 기록은 현재 브라우저의 IndexedDB에 저장된다. 실제 기록의 감정 분석은 연결 전이므로 저장 후 ‘분석 대기’로 표시된다. |
| 현재 시연 모드 | 분석된 카드 공개, 도감, 감정 통계, 공유 | 합성 예시 데이터를 사용한다. 방금 입력한 글의 실시간 AI 분석 결과라고 소개하지 않는다. |

## 2. 발표 전 준비

1. 개인 일기가 없는 시연 전용 브라우저 프로필을 준비한다. 시작할 때 시연 모드는 끄고, 당일 기록이 없는 상태인지 확인한다. 실제 기록은 하루 한 편이므로 반복 시연 때에는 당일 기록을 수정하는 흐름으로 바꾸거나 별도 시연 프로필을 사용한다.
2. 가정한 로그인 화면에서 기록 화면으로 넘어가는 경로를 준비한다. 로그인 화면이 아직 없다면 로그인 시안이나 슬라이드를 보여준 뒤 프론트엔드로 전환한다고 사전에 알린다.
3. 발표 화면 크기와 테마를 고정하고, 글자가 잘 보이는지 확인한다. 시연 중 테마 변경은 생략한다.
4. 아래 예시 글을 준비하고, 입력 시간을 줄이려면 붙여넣기를 사용한다.
5. 프로필의 ‘시연 모드’를 켜면 예시 기록 목록으로 이동하는지 확인한다. 분석이 끝난 예시 기록 한 편과 통계를 보여줄 월을 미리 골라 둔다.
6. 예시 카드 공개 연출을 한 번 확인하고, 본 시연 전에는 실제 모드로 되돌린 뒤 새로고침한다. 같은 예시 카드를 이미 열어 본 상태라면 공개 연출이 다시 나오지 않을 수 있으므로 리허설 후 초기 상태를 확인한다.
7. 예시 카드의 공유 미리보기와 PNG 다운로드가 동작하는지 확인한다. 다운로드한 파일과 주요 화면 캡처는 시연 중 문제가 생겼을 때 사용할 예비 자료로 준비한다.

### 입력할 예시 글

> 오늘 팀 프로젝트 발표 준비를 마쳤다. 처음에는 긴장했지만 팀원들과 함께 정리하니 마음이 한결 가벼워졌다. 서로 부족한 부분을 채워 준 덕분에 뿌듯했고, 도와준 팀원들에게 고마웠다.

이 글은 저장 동작을 보여주기 위한 입력이다. 특정 감정이나 등급의 카드가 나온다고 예고하지 않는다.

## 3. 5분 진행표

| 시간 | 화면과 조작 | 전달할 내용 |
| --- | --- | --- |

| 0:30~1:30 | 일기 입력 → ‘기록하고 카드 받기’ | 하루 한 편 기록과 실제 저장 |

| 1:55~2:40 | 분석된 예시 기록 열기 → 카드 공개 | 기록을 카드로 확인하는 경험 |
| 2:40~3:15 | ‘도감에 넣기’ → 도감 상세와 목록 | 감정별 카드 수집과 연결 기록 |

| 4:40~5:00 | 공유 닫기 → 기록 탭 | 핵심 가치 정리와 마무리 |

## 4. 단계별 조작과 발표 멘트

### 단계 1 로그인과 서비스 소개

**조작:** 준비된 로그인 화면에서 시연용 계정으로 진입하고 기록 화면을 연다. 로그인 시안을 사용하는 경우에는 성공 후 화면을 전환하는 흐름임을 밝힌다.

**발표 멘트**

> “오늘의 모먼트는 하루의 경험을 글로 남기고, 감정 카드와 통계로 돌아보는 서비스입니다. 로그인 화면이 준비되어 있다는 가정으로 사용자 흐름을 보여드리겠습니다. 먼저 기록 화면으로 들어가겠습니다.”

**확인할 화면:** 기록·통계·도감 탭과 일기 작성 영역. 모바일에서는 하단의 세 탭을 짚어 준다.

### 단계 2 오늘의 기록 작성과 저장

**조작:** 기록 탭에서 예시 글을 입력하고 ‘기록하고 카드 받기’를 누른다. 모바일의 버튼 이름은 ‘카드 받기’다. 저장 후 ‘기록은 잘 저장됐어요’와 분석 대기 안내가 표시되는지 확인한다.

**발표 멘트**

> “오늘 있었던 일을 자유롭게 적습니다. 사용자가 감정을 직접 고르는 대신, 글을 남기는 데 집중하도록 구성했습니다. 기록은 하루 한 편씩 남길 수 있습니다. 저장 버튼을 누르면 기록이 보관됩니다.”

**확인할 화면:** 저장 후 분석 대기 패널. 현재 버전에서는 이 단계에서 분석 완료 카드가 자동으로 나오지 않는다.

### 단계 3 시연 모드 전환 안내

**조작:** ‘기록으로 돌아가기’를 누르고, 상단 아바타로 프로필을 연다. ‘시연 모드’를 켜고 예시 기록 목록으로 이동한다.

**발표 멘트**

> “방금 작성한 기록은 실제로 저장됐습니다. 현재 프론트에는 새 감정 분류 모델이 연결되기 전이라 실제 글은 분석 대기로 표시됩니다. 이어서 보실 카드와 통계는 시연 모드에 준비된 합성 예시입니다.”

**확인할 화면:** 시연 모드 표시와 예시 기록 목록. 방금 작성한 글과 합성 예시를 구분해 소개한다.

### 단계 4 감정 카드 공개

**조작:** 미리 골라 둔 분석 완료 예시 기록을 연다. 자동 공개 연출이 끝날 때까지 기다린 뒤 카드의 감정 이름과 단계를 보여준다. 건너뛰거나 카드를 눌러 연출을 단축하는 동작은 넣지 않는다.

**발표 멘트**

> “분석이 완료된 기록은 이런 카드로 확인할 수 있습니다. 카드의 그림과 색으로 감정을 표현하고, 공개 연출을 통해 하루의 기록을 하나의 결과물로 만나는 경험을 제공합니다.”

**확인할 화면:** 공개된 카드, 감정 이름, 단계, ‘도감에 넣기’와 ‘공유하기’ 버튼.

확률에 관한 질문을 받으면 “모델이 해당 분류를 선택한 확률이며, 감정의 강도나 모델 전체 정확도를 뜻하지 않습니다”라고 설명한다. 단계와 등급 효과도 구분하고, 높은 등급을 감정이 더 좋거나 건강하다는 의미로 소개하지 않는다.

### 단계 5 도감에서 모인 카드 확인

**조작:** ‘도감에 넣기’를 눌러 해당 카드 상세로 이동한다. 연결 기록과 단계 안내를 보여준 뒤 도감 목록에서 긍정·부정·중립 탭을 한 번 전환한다.

**발표 멘트**

> “카드는 도감에서 감정별로 모아 볼 수 있습니다. 긍정·부정·중립의 세 대분류 아래 아홉 가지 감정과 세 단계 카드가 있어 총 27칸으로 구성됩니다. 카드에 연결된 기록을 확인하면서 어떤 날 이런 감정을 남겼는지 돌아볼 수 있습니다.”

**확인할 화면:** 대분류 탭, 카드 목록, 카드 상세의 연결 기록. 예시 도감은 이미 채워져 있을 수 있으므로 방금 버튼을 눌러 새로운 카드 수가 증가했다고 설명하지 않는다.

### 단계 6 통계로 감정 흐름 돌아보기

**조작:** 통계 탭을 누르고, 리허설에서 골라 둔 예시 기록이 있는 월로 이동한다. 진입 연출이 끝나면 요약 카드, 긍정 추이, 감정 분포, 감정 달력을 차례로 짚는다. 시간 여유가 있으면 요일별 마음을 보여준다.

**발표 멘트**

> “기록이 쌓이면 한 달의 흐름을 통계로 확인할 수 있습니다. 기록 수와 감정 분포를 보고, 긍정 추이와 달력으로 시기별 변화를 살펴봅니다. 이 화면은 예시 기록을 기준으로 보여드리고 있습니다.”

**확인할 화면:** 선택한 월과 그래프. 추이는 긍정 비율의 3일 이동평균이며, 심리 진단이나 미래 감정 예측으로 설명하지 않는다.

### 단계 7 공유 범위 선택과 이미지 저장

**조작:** 도감 탭에서 획득한 예시 카드의 상세를 열고 ‘공유하기’를 누른다. 공유 미리보기를 보여주고 인용 문장 표시를 껐다 켠 뒤 ‘이미지로 저장’을 누른다. 내려받은 PNG를 열어 결과를 보여준다.

**발표 멘트**

> “기록 전체를 공개하지 않고 카드 이미지로 남길 수 있습니다. 기본으로 들어가는 첫 문장은 최대 40자이며, 인용 문장을 끄면 이미지에서 제외할 수 있습니다. 분석 수치도 기본적으로 숨겨져 있어 공유 전에 공개 범위를 확인할 수 있습니다.”

**확인할 화면:** 인용 문장 옵션에 따라 달라지는 미리보기와 1080×1350 PNG. 인용 문장 외의 일기 본문은 공유 이미지에 포함되지 않는다.

스토리 기능을 추가로 보여줄 때는 기기 공유 창 또는 1080×1920 이미지 저장 흐름을 사용한다. 인스타그램에 자동 게시된다고 설명하지 않는다. 기본 5분 시연에서는 이미지 저장까지만 진행한다.

### 단계 8 기록 화면으로 돌아와 마무리

**조작:** 공유 화면을 닫고 기록 탭으로 돌아온다. 최근 기록과 카드 달력을 보여주며 마친다. 이때 화면은 계속 시연 모드임을 유지한다.

**발표 멘트**

> “오늘의 모먼트는 글을 남기는 것에서 시작해, 카드로 기억하고 통계로 돌아보는 흐름을 제공합니다. 현재 실제 기록 저장과 프론트 화면을 구현했으며, 감정 카드와 통계 경험은 합성 예시로 보여드렸습니다. 다음 연결 단계는 새 감정 분류 모델의 실제 분석 결과를 이 흐름에 붙이는 것입니다.”

## 5. 상황별 대처

| 상황 | 대응 |
| --- | --- |
| 로그인 화면이 준비되지 않음 | 로그인 시안 또는 슬라이드에서 진입 가정을 설명하고, 준비된 프론트의 기록 화면으로 전환한다. 실제 인증 성공이라고 설명하지 않는다. |
| 오늘 기록이 이미 있음 | 당일 기록 수정 흐름을 사용한다. 발표 중 개인 기록 전체를 지우지 않는다. |
| 저장 실패 안내가 나옴 | 입력 내용이 남아 있는지 확인하고 ‘다시 시도’를 누른다. 계속 실패하면 저장 실패 상태라고 밝히고, 실제 저장 성공을 주장하지 않은 채 시연 모드의 나머지 화면으로 넘어간다. |
| 카드가 분석 대기로만 보임 | 실제 기록에서는 정상적인 현재 상태다. 프로필의 시연 모드를 켜고 분석 완료 예시를 연다. |
| 예시 카드 공개 연출이 다시 나오지 않음 | 이미 열어 본 예시인지 확인한다. 다른 분석 완료 예시를 열거나, 시연 전 새로고침 후 시연 모드에 다시 진입한다. |
| 통계가 비어 있음 | 시연 모드인지 확인하고 예시 기록이 있는 월로 이동한다. |
| 다운로드가 차단됨 | 공유 미리보기와 리허설에서 저장한 예시 PNG를 보여준다. 내려받지 못한 상태를 성공으로 소개하지 않는다. |
| 발표 시간이 부족함 | 로그인 → 실제 저장과 분석 대기 → 시연 모드 → 예시 카드 → 통계 순서로 줄인다. 도감 상세와 파일 열기는 생략한다. |

## 6. 예상 질문과 답변

**방금 입력한 글을 AI가 분석한 것인가요?**

현재 실제 글은 저장 후 분석 대기로 표시됩니다. 카드 공개와 통계는 합성 예시 데이터로 시연하며, 실제 분석 연결은 후속 작업입니다.

**로그인하면 다른 기기에서도 같은 기록을 볼 수 있나요?**

이 시나리오에서는 로그인 화면만 가정했습니다. 현재 프론트의 기록은 브라우저별로 저장되므로 계정 기반 동기화는 별도 구현이 필요합니다.

**카드 확률이 높으면 더 강한 감정인가요?**

확률은 해당 감정 분류에 대한 모델의 선택 확률입니다. 감정 강도나 서비스 전체의 정확도를 의미하지 않습니다.

**일기 전체가 공유되나요?**

공유 이미지에는 카드와 선택한 정보가 들어갑니다. 인용은 기본적으로 첫 문장 최대 40자이며 끌 수 있고, 나머지 본문은 이미지에 포함되지 않습니다.

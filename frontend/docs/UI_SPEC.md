## 실제 화면 규칙
상단 오른쪽은 보관함(보관 상자)·설정(톱니바퀴) 순서의 선 아이콘 버튼입니다. 아이콘은 24px, 터치 영역은 화면 높이와 관계없이 44×44px이며 테마의 글자색을 따릅니다. 각 버튼은 접근성 이름과 기본 툴팁을 제공하고 Enter·Space로 실행합니다.

진입·복귀 흐름은 [USER_FLOWS](design/USER_FLOWS.md), 조작·복구는 [PATTERNS](design/PATTERNS.md)를 따릅니다.
- WF-01: 빈 입력은 ST-01. 실제 기록 제출은 ST-02이며 모델 호출은 하지 않습니다.
- WF-02, ST-09~12: 예시 결과 카드. 반올림 전 최다 확률 <30% 빈 카드, 30~60% 미만 1단계, 60~90% 미만 2단계, 90% 이상 3단계. 동률 안내를 유지합니다.
- WF-03~05, ST-07: 목록→상세→수정/삭제. 수정하면 기존 분석 버전을 무효화합니다. 하루 한 편/여러 편과 원래 날짜 유지 규칙은 README를 따릅니다.
- WF-06: 테마·모드 선택 즉시 반영, 표시 설정은 localStorage, 실제 기록·초안·기록 방식은 IndexedDB에 저장. 예시 전환은 실제 기록과 분리합니다.
- WF-07~10, ST-04~06: 추이·월간·분포, 날짜 목록. 기록 없음·분석 없음·분석 하루를 구분합니다.
- WF-11~14: 유형·단계별 해제, 미발견, 연결 기록. 유효한 마지막 기록이 사라지면 다시 잠깁니다.
- ST-08: 카드 저장 실패 안내. 분석 실패와 서로 다른 상태입니다.
## 와이어프레임과 앱의 차이
와이어프레임은 고정 날짜·설명용 집계·흑백 도형입니다. 실제 입력·분석·다운로드를 실행하지 않습니다. screens.json의 actions는 화면 링크 목록이며 실제 이벤트 핸들러가 아닙니다. 앱은 app.js의 상태와 뷰 모듈로 전환합니다. 분석 실패는 도메인 상태에 존재하지만 별도의 기존 ST 프레임은 없으며 추가 후보입니다. 긴 원문 스크롤·저장 중 로딩은 주석 중심이고 실화면 확인이 필요합니다.
기록 상세는 카드 앞뒷면을 뒤집어 읽고 별도 확대 읽기 대화상자를 제공합니다. 키보드 Enter/Space와 대화상자 Esc·초점 복귀를 지원합니다. 스크린리더와 물리적 모바일 기기 검증은 별도로 필요합니다. 신규 API·계정·서버 저장은 이번 범위가 아닙니다.


## 통합 화면 추가 규칙

- 6개 테마의 밝음·어두움 모드에서 카드 효과는 공통입니다. 설정의 `카드 효과 켜짐/꺼짐` 버튼(`aria-pressed`)으로 전환하며 localStorage `card-motion`에 `on/off`를 저장합니다. 저장된 선택이 없으면(기존 `auto`·누락·잘못된 값 포함) OS 움직임 줄이기 설정을 따릅니다. 움직임 줄이기가 켜져 있으면 꺼짐, 아니면 켜짐입니다. 저장된 `on`/`off`는 OS 설정보다 우선합니다. 사용자가 고른 켜짐은 OS 움직임 줄이기 설정과 관계없이 카드의 빛·기울기·뒤집기 애니메이션을 허용합니다. 꺼짐은 빛·기울기·애니메이션을 끄고 즉시 뒤집기를 유지합니다. 모바일은 본문 밖 터치·드래그에 즉시 반응하고 해제·취소 시 초기화합니다. 본문 스크롤·선택과 짧은 탭 뒤집기는 유지하며 드래그·길게 누르기는 뒤집지 않습니다. 보관함 썸네일·도감과 정적 PNG에는 상호작용 효과를 추가하지 않습니다.

### 기록 작성·회고 보조 (모델 분석을 대체하지 않음)

- **작성창 글자 수**
  - `n / 10,000자`로 표시합니다. 9,000자부터 경고하고, 넘으면 초과 글자 수를 표시합니다. 자동으로 자르지 않습니다.
  - 모바일에서는 경고 단계부터만 보입니다.
- **예시 모드에서 저장:** 실제 기록으로 전환된다는 확인 대화상자를 먼저 띄웁니다.
- **작성 질문**
  - 「무엇을 쓸까요?」는 날짜별 질문(질문 풀 18개)을 보여 주고, 「다른 질문」 버튼으로 바꿀 수 있습니다.
  - 질문은 참고용입니다. 모델 입력이 오염되지 않도록 본문에 넣지 않습니다.
- **보관 한도:** 실제 기록이 25편 이상이면 남은 편수를 보여 줍니다. 30편이 되면 한도를 안내하고 「백업 후 정리하기」로 설정 › 데이터 관리를 엽니다.
- **돌아보기 달력**
  - 이전 달·다음 달 버튼이 있고, 다음 달 버튼은 이번 달에서 비활성입니다.
  - 오늘 날짜를 강조합니다(`aria-current="date"`).
  - 유효한 분석이 있는 날은 대표 소분류 색 점을 날짜 숫자 아래에 표시합니다. 분석 대기 기록에는 색을 붙이지 않습니다.
- **월간 요약**
  - 유효한 분석이 3편 이상일 때만 "가장 큰 비중" 소분류와 대분류 비중을 보여 줍니다. 그 미만이면 필요한 편수를 안내합니다.
  - 동률인 소분류가 3개 이상이면 "여러 감정이 고르게"로 표현합니다.
  - 분류 확률이 감정 강도가 아니라는 안내를 유지합니다.
- **대기 카드:** 앞면 제목은 "분석 대기"입니다. 보관 상태는 카드 아래 설명에만 표시합니다.
- **상세 화면 돌아가기:** 홈에서 열었으면 「홈으로」, 보관함·돌아보기·도감에서 열었으면 「목록으로」로 출발한 화면에 돌아갑니다. 삭제한 뒤에도 같은 화면으로 갑니다.
- **삭제 되돌리기**
  - 삭제는 확인 후 즉시 저장합니다. 그 뒤 `#app` 밖의 토스트(`role=status`)로 8초 동안 「되돌리기」를 제공하며, 포인터나 포커스가 토스트에 있으면 시간을 멈춥니다.
  - 되돌리면 같은 id·version·본문으로 복원해 다시 저장합니다.
  - 전체 삭제, 예시 모드 전환, 30편 한도에서는 되돌리기를 제공하지 않습니다.
- **첫 실행 안내:** 기록이 없을 때 홈 요약에 3단계(기록 → 감정 분석 모델 → 카드·도감)와 확률 의미를 안내합니다. 모바일에서는 제목만 표시합니다.

- 기본 테마는 Lemon & Cocoa + 밝음이며 기존 선택은 유지합니다. 기존 5개 테마도 계속 제공합니다.
- 카드 앞면은 감정별 3D 캐릭터·감정명·단계·확률·동률 안내를 표시합니다. 뒷면은 기록 본문이며 본문 스크롤·선택 후에는 자동 뒤집지 않습니다.
- ‘기록 크게 보기’는 원문을 텍스트로 삽입합니다. 닫기·Esc 후 실행 버튼으로 초점을 돌려줍니다.
- 보관함은 모든 너비에서 1열이며 첫 줄 최대 2줄·날짜와 시각·감정 상태 순서로 표시합니다. 캐릭터는 48px 보조 썸네일입니다.
- 저장소 복원 중에는 변경 컨트롤을 비활성화합니다. 저장 실패·충돌은 원문을 유지하고 재시도 또는 복사 후 새로고침을 안내합니다.
- 초안 지우기·기록 전체 삭제는 두 번 확인합니다. 전체 삭제는 표시 설정과 예시 기록에 영향을 주지 않습니다.


## 카드 프레임·조작 단순화 (2026-11-09)

카드 앞면·뒷면·빛·클릭 영역은 공통 2:3 프레임(최대 360×540px)을 사용합니다. 효과 여백 16px을 제외한 가용 크기에 맞춰 축소하며 안내는 프레임 밖에 둡니다. 테마는 색상과 재질을 바꾸며 카드의 기하와 동작은 유지합니다.

카드에는 기록 읽기·이미지 저장·더보기를 기본 노출합니다. 기록 읽기는 확대 읽기 대화상자를 직접 열고 닫기·Esc 후 같은 버튼으로 초점을 돌려줍니다. 더보기에서 수정·도감·삭제에 접근합니다. 480px 이하에서는 기록 읽기를 첫 행 전체 너비로 배치합니다. 대기·실패 카드는 다운로드를 제공하지 않습니다. 서비스명은 작성 화면 복귀 버튼입니다. 작성 더보기에서 초안을 지우며 저장 재시도는 저장 실패 시 노출합니다. 삭제는 취소가 기본 초점인 확인 대화상자를 거칩니다. 수정 취소는 원문을 유지합니다.

설정의 기록 방식·예시 모드·데이터 관리는 접이식 항목이며, 예시 전환은 스위치입니다. 통계 종류는 선택 상자, 월은 월 입력으로 조작합니다. 발견한 도감 슬롯은 연결 기록으로 바로 이동합니다. 키보드·터치·Esc·초점 복귀를 검증하며 PNG와 저장 데이터 형식은 유지합니다.

## 기록 중심 UI (2026-11-09)

작성은 3:2 배치, 최소 180px 입력, 별도 하단 기록 버튼을 사용합니다. 입력 내용과 보관 안내는 내부에서 스크롤합니다. 저장 상태와 분석 상태는 독립적으로 표시하며 실패 시 기록 보관 성공 문구를 표시하지 않습니다. 돌아보기 최초 선택은 월간 기록이고 이후 탐색 중 선택을 유지합니다. 카드 유형 프레임에서 WF-04로 직접 이동하는 링크는 실제 앱의 기록 읽기 대화상자를 설명하는 링크입니다.

## 3+10 감정 표시

카드와 지난 기록은 대표 소분류의 대분류·소분류명을 표시합니다. 도감은 대분류별 선택지와 30슬롯을 제공하며 중립 4종을 표식으로 구분합니다. 감정 분포는 대분류 합계와 10개 소분류를 모두 표시하고 미분석을 제외합니다. [분석 연동 계약](API_CONTRACT.md)을 기준으로 검증합니다.


## 메인 기능 통합 (2026-11-11)

상단 메뉴는 오늘 쓰기·지난 기록·돌아보기·설정입니다. 작성 도움말은 펼쳐 보는 예시 질문이며 원문에 삽입하지 않습니다. 목록은 본문 검색·날짜·즐겨찾기를 함께 적용하고 페이지당 6편을 표시합니다. 검색 조건 변경은 첫 페이지로 이동하며 한글 조합 입력과 커서를 보존합니다. 월간 캘린더 날짜를 누르면 해당 날짜의 기록 목록으로 이동합니다.

기록 상세에서 즐겨찾기를 전환하고 설정 → 데이터 관리에서 JSON 내보내기·미리보기·합치기를 제공합니다. 추가·동일·충돌을 표시하며 충돌·합산 30편 초과는 전체 합치기를 차단합니다. 데이터 계약과 이전 절차는 [README](../README.md#메인-기능-통합-2026-11-11)를 참고하세요.

## 현재 화면: 요약 홈과 테마 갤러리 (2026-11-14)

이 절은 이전 작성·상단 메뉴·테마 선택 배치 명세를 대체합니다. 기록·분석·도감의 도메인 규칙은 유지합니다.

- 홈(`write`): 작성창과 최신 카드 상태, 최근 기록 최대 3편. PC 3:2·모바일 1열. 저장 후 `write`를 유지하며 요약을 갱신합니다. 저장 오류에는 성공 문구를 표시하지 않고 원문·재시도를 유지합니다.
- 탐색: 서비스명은 일반 텍스트, 오늘·기록·메뉴가 상시 노출됩니다. 메뉴에서 돌아보기·도감·설정에 접근합니다. 화면 크기 변경은 열린 메뉴와 입력 초점을 유지합니다.
- 작성 옵션: 도움말·초안 지우기·보관 안내. 기본 버튼은 5개, 최근 기록 행 최대 3개를 포함하면 8개입니다. 오류 시 재시도는 별도 노출합니다.
- 기록: 검색과 한 열 목록, 접이식 즐겨찾기 필터, 조건이 있을 때만 초기화. 상세 동작은 읽기·가능할 때 이미지 저장·더보기이며 즐겨찾기·수정·삭제·도감은 더보기로 이동합니다.
- 테마(`themes`): 설정의 현재 테마 견본에서 진입합니다. 9개 썸네일을 3열/2열로 표시하며 현재 적용 테마에 문자·체크 표시를 제공합니다. 모드 선택은 미리보기용이며 적용 전 저장하지 않습니다.
- 테마 미리보기: 합성 기록으로 배경·패널·버튼을 표시하는 모달입니다. 닫기·Esc 후 같은 썸네일로 초점 복귀. 단일 적용 버튼으로 테마와 모드를 함께 저장하고 갤러리로 돌아옵니다. 미리보기에 실제 일기 원문을 넣지 않습니다.
- 새 그림 테마: forest·sunset·starlight. 밝음/어두움 모두 지원하며 원본 SVG를 내장합니다. 그림은 외곽 장식이고 기록 면은 불투명합니다. PNG에는 기존 카드 프레임과 캐릭터·테마 팔레트를 사용합니다.
- 호환성: 기존 6개 ID와 저장 키, 기본 Lemon & Cocoa + 밝음, 기록·초안 구조를 유지합니다. 저장소 차단 시 테마는 현재 실행에 적용합니다.


## 현재 테마 및 모바일 배치 보정

9개 테마의 라이트/다크 18개 항목을 각각 사용 버튼으로 선택합니다. 갤러리의 전체/라이트/다크 분류는 필터이며 OS 설정과 연동하지 않습니다. 이전 system 설정은 같은 테마의 light로 저장 변환합니다. 로고와 이름은 초안을 유지하는 메인 복귀 버튼이며 헤더는 로고·기록·메뉴입니다. 모바일 작성 화면은 상태·최근 1편까지 320×568 이상 세로 화면에 배치합니다. 긴 본문은 입력창 내부에서 스크롤합니다. 패널 28px·입력 18px의 공통 모서리를 모든 테마에 적용합니다.


## 테마 직접 선택 및 모바일 UX 보정

테마 카드 전체가 미리보기 버튼이며 별도 사용 버튼은 없습니다. 미리보기에서 적용을 확정하고 취소 시 분류·스크롤·초점을 유지합니다. 적용 중인 항목은 테두리와 체크, 현재 테마 안내로 표시합니다. 이미 적용 중인 항목의 재적용은 비활성화합니다. 분류는 동일 너비·줄바꿈 없는 최소 44px 영역입니다.

모바일 도움말과 긴 오류 원인은 안내 대화상자로 표시합니다. 저장 실패 시 기존 주요 버튼이 재시도로 바뀌고 처리 중 중복 클릭을 막습니다. 예시 모드는 작성 상단에서 항상 구분합니다. 데이터·테마 저장 키와 API는 변경하지 않습니다.

회귀 검사: `node frontend/tests/ux.cjs`(루트 기준). 320×568~390×844에서 버튼 겹침·페이지 넘침, 도움말 표시, 오류 상세·재시도·원문 보존, 예시 표식, 카드 직접 클릭·필터·적용·취소·키보드 초점을 검증합니다.

## 감성 리프레시: 상단 바·탭바·새 카드 연출 (2026-11-16)

- **기본 테마** `blossom`(블라썸 로즈): 크림 배경, 더스티 로즈 액션, 웜 플럼 텍스트를 씁니다. 감정 색은 공용 토큰을 그대로 써서 대비 계약을 유지합니다. 테두리 대신 그림자로 영역을 나누고, 모서리는 30px·pill로 둥글게 합니다. 홈 요약 패널은 ±0.5° 기울여 '손으로 붙인' 느낌을 주며 모바일에서는 기울이지 않습니다. 이미 테마를 선택한 사용자의 선택은 유지됩니다.
- **상단 바(카카오톡형)**: 왼쪽에 작은 앱 이름과 큰 화면 제목(오늘·기록·돌아보기·도감·설정)을 둡니다. 탭 묶음은 하나뿐입니다.
  - 960px 이상: 탭이 헤더 오른쪽의 pill 세그먼트로 보입니다.
  - 959px 이하: 같은 `nav.tabs`가 화면 하단 고정 탭바(아이콘+라벨, safe-area 반영)가 됩니다.
  - 기존 더보기(`main-menu`)는 제거했습니다. 탭은 기존 `data-action`(`write`, `archive-records`, `review-month`, `catalog`, `settings`)을 그대로 쓰고, 현재 탭은 `aria-current="page"`로 표시합니다.
- **감정 추이 그래프**: Catmull-Rom 곡선을 쓰고, 제어점은 이웃 값 사이로 제한해 실제 값보다 튀어 오르지 않게 합니다(`DiaryStatistics.smoothSegments`). 선 아래에는 감정색 그라데이션을 깔고, 격자선은 옅은 점선으로 그립니다. 범례는 칩 형태입니다. 분석이 없는 날은 지금처럼 선을 끊고, 색약 사용자를 위한 대시 패턴도 유지합니다. 점에 마우스를 올리면 날짜·비중이 보입니다.
- **새 카드 연출(mymind 업적 배지 참고)**: 도감 칸(감정×단계)이 처음 열리면 화면 하단에 배지가 떠오릅니다. 카드가 스프링 모션으로 튀어나오고, 광택이 한 번 지나가고, 반짝이 12개가 퍼진 뒤 약 3.2초 후 사라집니다.
  - 배지는 클릭을 가로막지 않습니다(`pointer-events: none`). 카드 효과를 끄거나 동작 줄이기 설정이면 표시하지 않습니다.
  - 새 칸 판정은 `DiaryCards.unlockedKeys/newlyUnlocked`로 메모리에서만 비교하며 저장 스키마는 바꾸지 않습니다. 실제 기록은 저장소 복원 직후를 기준점으로 삼아 새로고침해도 다시 재생하지 않고, 예시 모드는 처음 켤 때 재생합니다.
  - 백엔드와 아직 연결되지 않아 실제 기록은 '분석 대기'이므로, 현재는 예시 모드에서만 연출이 보입니다.
- **카드 열기**: 다른 카드를 열 때 0.42초 동안 살짝 떠오르며 나타납니다(`.flip-scene.card-enter`).

## UX 리뷰 반영 (2026-11-16)

근거: [UX_REVIEW_2026-11-16](design/UX_REVIEW_2026-11-16.md)
- 탭 라벨 "돌아보기" → "통계"(화면 제목 "감정 통계"). `data-action="review-month"`는 그대로입니다.
- 추이 범례에 "선 끊김 = 분석 없는 날" 칩을 추가하고, 격자선·축 글자 대비를 높였습니다. 모바일 탭 라벨은 12px입니다.
- 분석 대기 카드 문구: "감정 분석 연결 준비 중".
- 기록 목록에 최신 순/오래된 순 토글(`[data-sort]`, `aria-pressed`)을 둡니다. 카드 필터도 "필터 · 적용 중"에 반영합니다.
- 통계 캘린더·날짜 선택에서 그날 기록이 1편이면 목록을 거치지 않고 바로 상세를 엽니다.
- 블라썸 패널 기울임을 없애고 곡률을 30px로 통일했습니다. 다크 모드에서는 배경 그라데이션을 끕니다.
- 새 카드 배지 반짝이는 6개로 줄였습니다. 1.2초 안에 다른 카드를 연달아 열면 진입 모션을 생략합니다.
- 화면 제목은 넘치면 말줄임표로 줄입니다. 화상 키보드가 올라오면(`visualViewport` 높이 75% 미만) 하단 탭바를 숨깁니다.
- 캘린더·기록·정렬 버튼에 `:focus-visible` 외곽선을 표시합니다.
- 저장·삭제 완료 시 하단에 1.8초 토스트(`#moment-toast`, `aria-hidden`, 클릭 통과)를 띄웁니다. 낭독은 기존 `#feedback` 라이브 영역이 담당합니다.
- 기록 필터에 "카드 감정"(10소분류) 선택을 추가했습니다. 분석된 최신 버전 카드만 일치하며, 분석 대기 기록은 어떤 감정에도 포함되지 않습니다. 사용자가 감정을 고르는 기능이 아닙니다.
- 월 직접 선택은 기존 `#stats-month` 입력을 사용합니다. 실기기 키보드·Safari는 수동 확인이 필요합니다.

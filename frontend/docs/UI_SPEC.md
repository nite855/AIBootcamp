## 등급 시각화 강화·건너뛰기·움직임 줄이기 (2026-11-24, 이전 등급 효과·"항상 동일" 규칙보다 우선)

- 근거: `reference/카드 등급별 시각화 강화 방안.pdf`. 효과 영역을 테두리(1단계) → 프레임(2단계) → 표면·바깥(3단계)으로 넓히고, 재질(무광 → 반광 → 금속 → 홀로그램 포일)과 모양 단서(점선 테두리·모서리 꺾쇠·반짝임 점)로 색·움직임 없이도 등급을 구분합니다. 공용 카드 표면(`.card-fx-rim`·`.grade-aura`, `--fx-unit` 비례)에서 한 번에 적용됩니다.

| 등급 | 정적 층(항상 표시) | 동적 층(움직임 허용 시) |
|---|---|---|
| 빈 카드 | 점선 테두리 + 안쪽 그림자(빈 슬롯) + 무광 회색 막 | 없음(완전 정지) |
| 1단계 | 외곽 광채 + 안쪽 흰 하이라이트 선 + 위쪽 반광 광택 | 숨 쉬는 펄스(3.6초) |
| 2단계 | 얇고 선명한 안쪽 링 + 넓고 흐린 바깥 링 + 브러시드 메탈 프레임 띠 + 모서리 꺾쇠 4개 | 프레임 띠를 따라 서로 반대 방향으로 도는 빛 2개(4초) |
| 3단계 | 굵은 홀로그램 링 + 넓은 바깥 발광 + 흰 꺾쇠·반짝임 점 + 표면 전체 사선 프리즘 반사광 | 홀로그램 색 순환(6초), 반사광이 포인터·기울기(`--light-x/y`)를 따라 이동 |

- 공개 연출 범례: 빈 카드 "빈 슬롯", 1단계 "은은한 빛", 2단계 "금속 이중 링", 3단계 "홀로그램 포일". 펑이 시작될 때 제목(aria-live)이 "N단계 · 효과 카드예요"로 바뀝니다.
- **건너뛰기**: 봉인 중 안내 영역에 "건너뛰기" 버튼(44px 이상)이 있습니다. 두근두근·고조 중에 누르면 기다림만 건너뛰고 등급별 펑(1.7초)은 재생하며, 버튼이 "바로 보기"로 바뀝니다. 펑 중에 다시 누르거나 Esc를 누르면 결과로 바로 가고 초점은 `#card-info-title`로 갑니다. 카드 탭으로는 여전히 앞당기지 않으며, 건너뛴 연출은 다시 재생되지 않습니다.
- **깜빡임 완화**: 3단계 고조의 무지개 빛은 0.3초 점멸 대신 1.2초 완만한 맥동(WCAG 2.3.1 기준 이하), 흔들림 3px·1.5°·0.24초, 전체 화면 섬광 최대 불투명도 0.7.
- **움직임 줄이기**(`prefers-reduced-motion: reduce`): 즉시 공개하지 않고 같은 시간(1.5+1.2+1.7초)과 단계·문구를 유지합니다. 이동·흔들림·입자·섬광은 없고, 펑은 불투명도만 바뀌는 광채(빈 카드 제외)·정지 링(2단계 이상)·정지 방사광(3단계)과 카드 페이드로 진행합니다. 진행 막대는 JS 퍼센트로 채우고 "기기 설정에 맞춰 움직임을 줄여 보여드려요" 안내가 붙습니다. 카드의 정적 층은 그대로 남아 등급이 구분됩니다.
- 회귀 검사: `card-grade.cjs`(등급 사다리·건너뛰기·Esc·재생 없음·움직임 줄이기), `all-card-effects.cjs`(10테마×6폭, 단계별 애니메이션·배경 층 수).

## 터치 정책과 도감 복귀 (2026-11-23, 이전 pan-y 공통 규칙보다 우선)

- 목록 카드는 세로 스크롤·가로 기울기, 모달/도감 상세/공유/기록 앞면의 큰 카드는 모든 방향 기울기입니다. 큰 카드 바깥과 기록 뒷면 본문은 스크롤할 수 있습니다. 8px 초과 이동 시 목록 제스처 방향을 고정하고, 세로 이동은 포일만 종료하며 등급 애니메이션은 유지합니다. 드래그·취소·500ms 이상 누름은 열기/뒤집기로 처리하지 않습니다.
- 최초 크기 관찰과 카드 크기가 그대로인 모바일 주소창 높이 변화는 터치를 취소하지 않습니다. 카드의 실제 크기 변경·스크롤·창 비활성화는 좌표와 효과를 초기화합니다. 목록/상세별 터치 안내를 표시합니다.
- 도감 슬롯은 `aria-haspopup="dialog"`인 상세 열기 버튼이며 토글 선택 상태를 제공하지 않습니다. 상세를 닫으면 단계와 상세 선택을 지우고, 필터와 목록 위치는 유지합니다. 원래 카드에 초점을 복원한 뒤 포일을 초기화해 복귀가 선택 상태처럼 보이지 않도록 합니다. 실제 키보드 탐색에서만 중앙 초점 광택을 켭니다.
- `node tests/gesture-return.cjs`는 실제 목록 스크롤, 세로 상세 기울기, 뒤로/닫기/Escape 복귀의 선택 해제·초점 복원을 검사합니다.

## 모든 카드 효과·등급·반응형 통일 (2026-11-23, 이전 효과 규칙보다 우선)

- 기록 상세·모달, 오늘의 카드, 최근 기록·목록·달력, 도감 슬롯·상세, 통계 대표 카드, 획득 팝업, 공유 미리보기와 안내용 미니카드에 포인터 효과를 제공합니다. 잠금·분석 대기·실패·빈 카드도 중립 포일을 받으며 미발견 감정·등급을 노출하지 않습니다. 배경 장식용 부채꼴 실루엣은 카드 콘텐츠가 아닙니다. 저장 PNG는 기존 정적 출력으로 유지합니다.
- 공통 입력은 카드 안 상대 좌표로 각 축 ±9도, 기울기 전환 180ms·광택 전환 200ms입니다. 마우스·펜 이동과 터치에 반응하며, 작은 카드의 세로 스크롤은 브라우저에 맡깁니다. 8px 초과 드래그·500ms 이상 누름은 열기/뒤집기 탭으로 처리하지 않습니다. 키보드 초점에는 중앙 광택을 제공하고 기존 Enter/Space 동작을 유지합니다. 화면별 hover 상승은 공통 기울기로 대체하며 정적 배치는 유지합니다.
- 해제·취소·이탈·초점 이탈·창 비활성화·테마/뷰포트 변경 때 초기화합니다. 동적 카드와 모달은 중복 없이 연결하고 교체·닫기 때 이벤트와 예약 프레임을 정리합니다. 숫자 카운트업처럼 텍스트만 바뀌는 경우 전체 카드 스캔을 실행하지 않습니다.
- 등급은 화면에 관계없이 **1단계 감정색 고정 광채·단일 외곽선 / 2단계 숨 쉬는 광채(3.2초)·이중 링·회전광(4초) / 3단계 홀로그램 테두리(6초)·광채**입니다. 카드 폭에 비례하는 공통 반경·링 두께·간격을 사용합니다. 잠금·분석 대기·실패·빈 카드에는 등급 장식을 넣지 않습니다. 획득 예고·버스트 시간은 유지합니다.
- 모바일 모달에서도 안내를 표시합니다. 마우스는 “카드 위에서 마우스를 움직이면 포일이 반짝여요”, 터치는 “카드를 터치하고 움직이면 포일이 반짝여요”로 실제 입력에 따라 전환합니다. 기록·도감·통계 목록에는 영역별 안내를 한 번 표시하고, 상세·공유에는 별도 안내를 표시합니다. 모바일 도감의 세로 flex 배치에서 안내가 가로 화면 밖으로 밀리지 않도록 합니다.
- `tests/all-card-effects.cjs`는 도감과 통계의 공통 등급, 10테마·320/390/768/959/960/1440px, 터치 드래그·스크롤 취소·크기 변경, 안내의 화면 내 배치를 검사합니다. `modal-foil.cjs`와 `card-effects.cjs`는 모바일 안내·중립 카드·재열기·테마 전환·기존 뒤집기 동작을 검사합니다.

## 효과 안내와 카드 모달 보완 (2026-11-23, 아래는 최초 수정 이력)

- 분석된 카드 모달은 고정된 카드 영역 위에서 마우스를 움직이거나 카드를 터치·드래그하면 기울기와 포일 광택이 입력 위치를 따라갑니다. 해제·취소·마우스 이탈·테마 변경 시 초기화합니다. 모바일은 카드 영역만 드래그를 처리하며 본문·모달 스크롤은 유지합니다. 기기 기울기 센서는 사용하지 않습니다.

## 실제 화면 규칙
상단 오른쪽은 보관함(보관 상자)·설정(톱니바퀴) 순서의 선 아이콘 버튼입니다. 아이콘은 24px, 터치 영역은 화면 높이와 관계없이 44×44px이며 테마의 글자색을 따릅니다. 각 버튼은 접근성 이름과 기본 툴팁을 제공하고 Enter·Space로 실행합니다.

진입·복귀 흐름은 [USER_FLOWS](design/USER_FLOWS.md), 조작·복구는 [PATTERNS](design/PATTERNS.md)를 따릅니다.
- WF-01: 빈 입력은 ST-01. 실제 기록 제출은 ST-02이며 모델 호출은 하지 않습니다.
- WF-02, ST-09~12: 예시 결과 카드. 반올림 전 최다 확률 <30% 빈 카드, 30~60% 미만 1단계, 60~90% 미만 2단계, 90% 이상 3단계. 동률 안내를 유지합니다.
- WF-03~05, ST-07: 목록→상세→수정/삭제. 수정하면 기존 분석 버전을 무효화합니다. 하루 한 편/여러 편과 원래 날짜 유지 규칙은 README를 따릅니다.
- WF-06: 테마·모드 선택 즉시 반영, 표시 설정은 localStorage, 실제 기록·초안·기록 방식은 IndexedDB에 저장. 예시 전환은 실제 기록과 분리합니다.
- WF-07~10, ST-04~06: 추이·월간·분포, 날짜 목록. 기록 없음·분석 없음·분석 하루를 구분합니다.
- WF-11~14: 유형·단계별 해제, 미발견, 연결 기록. 유효한 마지막 기록이 사라지면 다시 잠깁니다.
- ST-08: 카드 저장 실패 안내. 분석 실패와 서로 다른 상태입니다.
## 와이어프레임과 앱의 차이
와이어프레임은 고정 날짜·설명용 집계·흑백 도형입니다. 실제 입력·분석·다운로드를 실행하지 않습니다. screens.json의 actions는 화면 링크 목록이며 실제 이벤트 핸들러가 아닙니다. 앱은 app.js의 상태와 뷰 모듈로 전환합니다. 분석 실패는 도메인 상태에 존재하지만 별도의 기존 ST 프레임은 없으며 추가 후보입니다. 긴 원문 스크롤·저장 중 로딩은 주석 중심이고 실화면 확인이 필요합니다.
기록 상세는 카드 앞뒷면을 뒤집어 읽고 별도 확대 읽기 대화상자를 제공합니다. 키보드 Enter/Space와 대화상자 Esc·초점 복귀를 지원합니다. 스크린리더와 물리적 모바일 기기 검증은 별도로 필요합니다. 신규 API·계정·서버 저장은 이번 범위가 아닙니다.


## 통합 화면 추가 규칙

- 6개 테마의 밝음·어두움 모드에서 카드 효과는 공통입니다. 설정의 `카드 효과 켜짐/꺼짐` 버튼(`aria-pressed`)으로 전환하며 localStorage `card-motion`에 `on/off`를 저장합니다. 저장된 선택이 없으면(기존 `auto`·누락·잘못된 값 포함) OS 움직임 줄이기 설정을 따릅니다. 움직임 줄이기가 켜져 있으면 꺼짐, 아니면 켜짐입니다. 저장된 `on`/`off`는 OS 설정보다 우선합니다. 사용자가 고른 켜짐은 OS 움직임 줄이기 설정과 관계없이 카드의 빛·기울기·뒤집기 애니메이션을 허용합니다. 꺼짐은 빛·기울기·애니메이션을 끄고 즉시 뒤집기를 유지합니다. 모바일은 본문 밖 터치·드래그에 즉시 반응하고 해제·취소 시 초기화합니다. 본문 스크롤·선택과 짧은 탭 뒤집기는 유지하며 드래그·길게 누르기는 뒤집지 않습니다. 보관함 썸네일·도감과 정적 PNG에는 상호작용 효과를 추가하지 않습니다.

### 기록 작성·회고 보조 (모델 분석을 대체하지 않음)

- **작성창 글자 수**
  - `n / 10,000자`로 표시합니다. 9,000자부터 경고하고, 넘으면 초과 글자 수를 표시합니다. 자동으로 자르지 않습니다.
  - 모바일에서는 경고 단계부터만 보입니다.
- **예시 모드에서 저장:** 실제 기록으로 전환된다는 확인 대화상자를 먼저 띄웁니다.
- **작성 질문**
  - 「무엇을 쓸까요?」는 날짜별 질문(질문 풀 18개)을 보여 주고, 「다른 질문」 버튼으로 바꿀 수 있습니다.
  - 질문은 참고용입니다. 모델 입력이 오염되지 않도록 본문에 넣지 않습니다.
- **보관 한도:** 실제 기록이 25편 이상이면 남은 편수를 보여 줍니다. 30편이 되면 한도를 안내하고 「백업 후 정리하기」로 설정 › 데이터 관리를 엽니다.
- **돌아보기 달력**
  - 이전 달·다음 달 버튼이 있고, 다음 달 버튼은 이번 달에서 비활성입니다.
  - 오늘 날짜를 강조합니다(`aria-current="date"`).
  - 유효한 분석이 있는 날은 대표 소분류 색 점을 날짜 숫자 아래에 표시합니다. 분석 대기 기록에는 색을 붙이지 않습니다.
- **월간 요약**
  - 유효한 분석이 3편 이상일 때만 "가장 큰 비중" 소분류와 대분류 비중을 보여 줍니다. 그 미만이면 필요한 편수를 안내합니다.
  - 동률인 소분류가 3개 이상이면 "여러 감정이 고르게"로 표현합니다.
  - 분류 확률이 감정 강도가 아니라는 안내를 유지합니다.
- **대기 카드:** 앞면 제목은 "분석 대기"입니다. 보관 상태는 카드 아래 설명에만 표시합니다.
- **상세 화면 돌아가기:** 홈에서 열었으면 「홈으로」, 보관함·돌아보기·도감에서 열었으면 「목록으로」로 출발한 화면에 돌아갑니다. 삭제한 뒤에도 같은 화면으로 갑니다.
- **삭제 되돌리기**
  - 삭제는 확인 후 즉시 저장합니다. 그 뒤 `#app` 밖의 토스트(`role=status`)로 8초 동안 「되돌리기」를 제공하며, 포인터나 포커스가 토스트에 있으면 시간을 멈춥니다.
  - 되돌리면 같은 id·version·본문으로 복원해 다시 저장합니다.
  - 전체 삭제, 예시 모드 전환, 30편 한도에서는 되돌리기를 제공하지 않습니다.
- **첫 실행 안내:** 기록이 없을 때 홈 요약에 3단계(기록 → 감정 분석 모델 → 카드·도감)와 확률 의미를 안내합니다. 모바일에서는 제목만 표시합니다.

- 기본 테마는 Lemon & Cocoa + 밝음이며 기존 선택은 유지합니다. 기존 5개 테마도 계속 제공합니다.
- 카드 앞면은 감정별 3D 캐릭터·감정명·단계·확률·동률 안내를 표시합니다. 뒷면은 기록 본문이며 본문 스크롤·선택 후에는 자동 뒤집지 않습니다.
- ‘기록 크게 보기’는 원문을 텍스트로 삽입합니다. 닫기·Esc 후 실행 버튼으로 초점을 돌려줍니다.
- 보관함은 모든 너비에서 1열이며 첫 줄 최대 2줄·날짜와 시각·감정 상태 순서로 표시합니다. 캐릭터는 48px 보조 썸네일입니다.
- 저장소 복원 중에는 변경 컨트롤을 비활성화합니다. 저장 실패·충돌은 원문을 유지하고 재시도 또는 복사 후 새로고침을 안내합니다.
- 초안 지우기·기록 전체 삭제는 두 번 확인합니다. 전체 삭제는 표시 설정과 예시 기록에 영향을 주지 않습니다.


## 카드 프레임·조작 단순화 (2026-11-09)

카드 앞면·뒷면·빛·클릭 영역은 공통 2:3 프레임(최대 360×540px)을 사용합니다. 효과 여백 16px을 제외한 가용 크기에 맞춰 축소하며 안내는 프레임 밖에 둡니다. 테마는 색상과 재질을 바꾸며 카드의 기하와 동작은 유지합니다.

카드에는 기록 읽기·이미지 저장·더보기를 기본 노출합니다. 기록 읽기는 확대 읽기 대화상자를 직접 열고 닫기·Esc 후 같은 버튼으로 초점을 돌려줍니다. 더보기에서 수정·도감·삭제에 접근합니다. 480px 이하에서는 기록 읽기를 첫 행 전체 너비로 배치합니다. 대기·실패 카드는 다운로드를 제공하지 않습니다. 서비스명은 작성 화면 복귀 버튼입니다. 작성 더보기에서 초안을 지우며 저장 재시도는 저장 실패 시 노출합니다. 삭제는 취소가 기본 초점인 확인 대화상자를 거칩니다. 수정 취소는 원문을 유지합니다.

설정의 기록 방식·예시 모드·데이터 관리는 접이식 항목이며, 예시 전환은 스위치입니다. 통계 종류는 선택 상자, 월은 월 입력으로 조작합니다. 발견한 도감 슬롯은 연결 기록으로 바로 이동합니다. 키보드·터치·Esc·초점 복귀를 검증하며 PNG와 저장 데이터 형식은 유지합니다.

## 기록 중심 UI (2026-11-09)

작성은 3:2 배치, 최소 180px 입력, 별도 하단 기록 버튼을 사용합니다. 입력 내용과 보관 안내는 내부에서 스크롤합니다. 저장 상태와 분석 상태는 독립적으로 표시하며 실패 시 기록 보관 성공 문구를 표시하지 않습니다. 돌아보기 최초 선택은 월간 기록이고 이후 탐색 중 선택을 유지합니다. 카드 유형 프레임에서 WF-04로 직접 이동하는 링크는 실제 앱의 기록 읽기 대화상자를 설명하는 링크입니다.

## 3+10 감정 표시

카드와 지난 기록은 대표 소분류의 대분류·소분류명을 표시합니다. 도감은 대분류별 선택지와 27슬롯을 제공하며 중립 3종을 표식으로 구분합니다. 감정 분포는 대분류 합계와 9개 소분류를 모두 표시하고 미분석을 제외합니다. [분석 연동 계약](API_CONTRACT.md)을 기준으로 검증합니다.


## 메인 기능 통합 (2026-11-11)

상단 메뉴는 오늘 쓰기·지난 기록·돌아보기·설정입니다. 작성 도움말은 펼쳐 보는 예시 질문이며 원문에 삽입하지 않습니다. 목록은 본문 검색·날짜·즐겨찾기를 함께 적용하고 페이지당 6편을 표시합니다. 검색 조건 변경은 첫 페이지로 이동하며 한글 조합 입력과 커서를 보존합니다. 월간 캘린더 날짜를 누르면 해당 날짜의 기록 목록으로 이동합니다.

기록 상세에서 즐겨찾기를 전환하고 설정 → 데이터 관리에서 JSON 내보내기·미리보기·합치기를 제공합니다. 추가·동일·충돌을 표시하며 충돌·합산 30편 초과는 전체 합치기를 차단합니다. 데이터 계약과 이전 절차는 [README](../README.md#메인-기능-통합-2026-11-11)를 참고하세요.

## 현재 화면: 요약 홈과 테마 갤러리 (2026-11-14)

이 절은 이전 작성·상단 메뉴·테마 선택 배치 명세를 대체합니다. 기록·분석·도감의 도메인 규칙은 유지합니다.

- 홈(`write`): 작성창과 최신 카드 상태, 최근 기록 최대 3편. PC 3:2·모바일 1열. 저장 후 `write`를 유지하며 요약을 갱신합니다. 저장 오류에는 성공 문구를 표시하지 않고 원문·재시도를 유지합니다.
- 탐색: 서비스명은 일반 텍스트, 오늘·기록·메뉴가 상시 노출됩니다. 메뉴에서 돌아보기·도감·설정에 접근합니다. 화면 크기 변경은 열린 메뉴와 입력 초점을 유지합니다.
- 작성 옵션: 도움말·초안 지우기·보관 안내. 기본 버튼은 5개, 최근 기록 행 최대 3개를 포함하면 8개입니다. 오류 시 재시도는 별도 노출합니다.
- 기록: 검색과 한 열 목록, 접이식 즐겨찾기 필터, 조건이 있을 때만 초기화. 상세 동작은 읽기·가능할 때 이미지 저장·더보기이며 즐겨찾기·수정·삭제·도감은 더보기로 이동합니다.
- 테마(`themes`): 설정의 현재 테마 견본에서 진입합니다. 9개 썸네일을 3열/2열로 표시하며 현재 적용 테마에 문자·체크 표시를 제공합니다. 모드 선택은 미리보기용이며 적용 전 저장하지 않습니다.
- 테마 미리보기: 합성 기록으로 배경·패널·버튼을 표시하는 모달입니다. 닫기·Esc 후 같은 썸네일로 초점 복귀. 단일 적용 버튼으로 테마와 모드를 함께 저장하고 갤러리로 돌아옵니다. 미리보기에 실제 일기 원문을 넣지 않습니다.
- 새 그림 테마: forest·sunset·starlight. 밝음/어두움 모두 지원하며 원본 SVG를 내장합니다. 그림은 외곽 장식이고 기록 면은 불투명합니다. PNG에는 기존 카드 프레임과 캐릭터·테마 팔레트를 사용합니다.
- 호환성: 기존 6개 ID와 저장 키, 기본 Lemon & Cocoa + 밝음, 기록·초안 구조를 유지합니다. 저장소 차단 시 테마는 현재 실행에 적용합니다.


## 현재 테마 및 모바일 배치 보정

9개 테마의 라이트/다크 18개 항목을 각각 사용 버튼으로 선택합니다. 갤러리의 전체/라이트/다크 분류는 필터이며 OS 설정과 연동하지 않습니다. 이전 system 설정은 같은 테마의 light로 저장 변환합니다. 로고와 이름은 초안을 유지하는 메인 복귀 버튼이며 헤더는 로고·기록·메뉴입니다. 모바일 작성 화면은 상태·최근 1편까지 320×568 이상 세로 화면에 배치합니다. 긴 본문은 입력창 내부에서 스크롤합니다. 패널 28px·입력 18px의 공통 모서리를 모든 테마에 적용합니다.


## 테마 직접 선택 및 모바일 UX 보정

테마 카드 전체가 미리보기 버튼이며 별도 사용 버튼은 없습니다. 미리보기에서 적용을 확정하고 취소 시 분류·스크롤·초점을 유지합니다. 적용 중인 항목은 테두리와 체크, 현재 테마 안내로 표시합니다. 이미 적용 중인 항목의 재적용은 비활성화합니다. 분류는 동일 너비·줄바꿈 없는 최소 44px 영역입니다.

모바일 도움말과 긴 오류 원인은 안내 대화상자로 표시합니다. 저장 실패 시 기존 주요 버튼이 재시도로 바뀌고 처리 중 중복 클릭을 막습니다. 예시 모드는 작성 상단에서 항상 구분합니다. 데이터·테마 저장 키와 API는 변경하지 않습니다.

회귀 검사: `node frontend/tests/ux.cjs`(루트 기준). 320×568~390×844에서 버튼 겹침·페이지 넘침, 도움말 표시, 오류 상세·재시도·원문 보존, 예시 표식, 카드 직접 클릭·필터·적용·취소·키보드 초점을 검증합니다.

## 감성 리프레시: 상단 바·탭바·새 카드 연출 (2026-11-16)

- **기본 테마** `blossom`(블라썸 로즈): 크림 배경, 더스티 로즈 액션, 웜 플럼 텍스트를 씁니다. 감정 색은 공용 토큰을 그대로 써서 대비 계약을 유지합니다. 테두리 대신 그림자로 영역을 나누고, 모서리는 30px·pill로 둥글게 합니다. 홈 요약 패널은 ±0.5° 기울여 '손으로 붙인' 느낌을 주며 모바일에서는 기울이지 않습니다. 이미 테마를 선택한 사용자의 선택은 유지됩니다.
- **상단 바(카카오톡형)**: 왼쪽에 작은 앱 이름과 큰 화면 제목(오늘·기록·통계·도감·설정, 11-16 UX 리뷰에서 "돌아보기"를 "통계"로 변경)을 둡니다. 탭 묶음은 하나뿐입니다.
  - 960px 이상: 탭이 헤더 오른쪽의 pill 세그먼트로 보입니다.
  - 959px 이하: 같은 `nav.tabs`가 화면 하단 고정 탭바(아이콘+라벨, safe-area 반영)가 됩니다.
  - 기존 더보기(`main-menu`)는 제거했습니다. 탭은 기존 `data-action`(`write`, `archive-records`, `review-month`, `catalog`, `settings`)을 그대로 쓰고, 현재 탭은 `aria-current="page"`로 표시합니다.
- **감정 추이 그래프**: Catmull-Rom 곡선을 쓰고, 제어점은 이웃 값 사이로 제한해 실제 값보다 튀어 오르지 않게 합니다(`DiaryStatistics.smoothSegments`). 선 아래에는 감정색 그라데이션을 깔고, 격자선은 옅은 점선으로 그립니다. 범례는 칩 형태입니다. 분석이 없는 날은 지금처럼 선을 끊고, 색약 사용자를 위한 대시 패턴도 유지합니다. 점에 마우스를 올리면 날짜·비중이 보입니다.
- **새 카드 연출(mymind 업적 배지 참고)**: 도감 칸(감정×단계)이 처음 열리면 화면 하단에 배지가 떠오릅니다. 카드가 스프링 모션으로 튀어나오고, 광택이 한 번 지나가고, 반짝이 12개가 퍼진 뒤 약 3.2초 후 사라집니다.
  - 배지는 클릭을 가로막지 않습니다(`pointer-events: none`). 카드 효과를 끄거나 동작 줄이기 설정이면 표시하지 않습니다.
  - 새 칸 판정은 `DiaryCards.unlockedKeys/newlyUnlocked`로 메모리에서만 비교하며 저장 스키마는 바꾸지 않습니다. 실제 기록은 저장소 복원 직후를 기준점으로 삼아 새로고침해도 다시 재생하지 않고, 예시 모드는 처음 켤 때 재생합니다.
  - 백엔드와 아직 연결되지 않아 실제 기록은 '분석 대기'이므로, 현재는 예시 모드에서만 연출이 보입니다.
- **카드 열기**: 다른 카드를 열 때 0.42초 동안 살짝 떠오르며 나타납니다(`.flip-scene.card-enter`).

## 카드 획득 연출·등급 이펙트 (2026-11-20)

- **흐름**: 기록 저장 → (저장소에 실제로 보관된 뒤) 카드 획득 화면 → '?'만 있는 봉인 카드 → 사용자가 누르거나 Enter/Space → 카드가 뒤집히며 등급 이펙트 → 카드와 정보 패널 공개.
  - 저장소 오류(IndexedDB 실패·차단)면 기록 화면에 머물러 오류와 "저장 재시도"를 그대로 보여 줍니다. 성공처럼 보이는 카드 화면으로 가지 않습니다.
  - 봉인 동안 실제 카드(`.flip-scene`), 정보 패널, 카드 아래 안내·버튼은 `visibility: hidden` + `inert`입니다. 제목이 등급을 미리 알려 주기 때문입니다.
  - 봉인 동안 정보 패널 자리(같은 grid 칸이라 공개 때 카드가 움직이지 않음, 모바일은 카드 아래)에 안내 `.seal-hint`를 둡니다. 내용: "오늘의 카드 · 아직 열지 않았어요", "어떤 카드가 나올까요?", 누르기·Enter/Space 안내, 등급 색 범례 4칸(분석 대기 은빛·1단계 민트·2단계 보라·3단계 금빛). 실제 기록일 때만 "AI 감정 분석이 연결되기 전에는 "분석 대기" 카드가 나와요" 안내를 붙입니다. 공개가 끝나면 안내를 지우고 정보 패널이 떠오르듯 나타납니다.

  - 봉인 조건: 실제 기록은 방금 저장한 버전만 봉인하고(`state.pendingReveal`), 지난 기록을 다시 열 때는 봉인하지 않습니다. 같은 날 다시 저장하면 새 버전이라 한 번 더 봉인됩니다. 예시 기록은 세션당 기록마다 한 번만 봉인하며, 원문을 수정해도 다시 봉인하지 않습니다. 누르기 전에 다시 렌더되면 봉인 상태를 유지합니다.
  - 연출 시간: 눌림 → 들림 → `rotateY` 180도(약 0.6초) → 반쯤 돌았을 때 버스트 → 1.7초에 마무리. 카드 효과가 꺼져 있으면(`data-motion="off"`) 연출 없이 바로 공개합니다.

- **프로필 아이콘**: 토끼·곰·고양이·병아리·구름·별 6종을 카드 블롭과 같은 화풍(안쪽 그림자·그레인·빛나는 알약 눈)의 256×256 투명 PNG로 바꿨습니다.

  - 가변 글꼴 하나(`font-weight: 45 930`)로 모든 굵기를 실제 글꼴로 그리고, 한글 11,172자 전부와 호환 자모를 담아 입력한 드문 음절도 시스템 글꼴로 바뀌지 않습니다.
  - 생성: `tools/subset-ui-fonts.py --pretendard <PretendardVariable.ttf>`.
  - 토큰: `--font-ui: "Moment Sans", "Pretendard", "Apple SD Gothic Neo", "Malgun Gothic", sans-serif`, `--font-display: "Bricolage Grotesque", "Moment Sans", …`.
  - 얇게 보이던 큰 제목(`font-weight: 300`)은 600으로, 12~13px 보조 문구의 400은 500으로 올렸습니다.
  - `index.html`은 약 4.1MB입니다. 와이어프레임 SVG(52개, 각자 글꼴 내장)는 이 변경으로 다시 만들지 않았습니다.

- 카드 안 그림은 Figma "Moment Card"의 `character · 블롭`(파일 `NaEAXNfEgTB3e3bPZJ0FkX`, 섹션 2028-9110)입니다. 12굽이 물결 블롭, 감정색 광채(r78·blur 14.3·.45), 흰 안쪽 그림자와 그레인, 빛나는 흰 알약 눈 2개로 구성하며 `scripts/blob-art.js`(`MomentBlob.blobSVG`)가 Figma 수치 그대로 그립니다. 감정은 모양이 아니라 색으로만 구분합니다(`--card-deep-*`, 예: 불안 `#8cc55a`). 예전 3D 토끼 PNG 9종과 중립 감정 모서리 표식(`data-emotion-mark`)은 쓰지 않으며 빌드는 빈 카드용 하트 PNG만 내장합니다.
- 큰 카드(1080×1512)는 Figma glass-window 비율을 따릅니다. 블롭 틀은 창 폭의 63%이고, 광채 여백을 포함한 SVG는 `x 180.2 · y 236.1 · 719.8` 크기입니다. 바닥 그림자는 감정색 .35, blur 13.2입니다. 미니카드·도감 슬롯은 SVG 폭 76%(= 틀 63%)입니다. `characterSVG()`를 거치므로 상세 카드·미니카드·도감·통계·축하 팝업·공유/카드 PNG가 같은 그림을 씁니다. 필터 id는 그림마다 다른 접두사를 붙입니다.
- 등급 광채(`.grade-aura`)는 카드에 딱 붙고(`inset 0`) 카드와 같은 모서리 반경 `--card-r`(= 카드 폭 × 96/1080, `.flip-scene`·`.mystery-card`의 cqw)을 씁니다. 바깥 링(2단계 점선, 3단계 홀로, 공개 펄스, 연출 rise 광채)은 `반경 = --card-r + inset`의 동심원입니다. 회귀 검사: `tests/card-grade.cjs`(데스크톱·모바일 `ringsHug`), `tests/card-effects.cjs`(폭 비례 반경), `tests/blob-art.test.cjs`.

## 통계 진입 연출 (2026-11-21)

- 통계 화면에 들어오면 그래프가 순서대로 그려집니다(약 1.5초): 요약 카드 페이드와 숫자 카운트업(0 → 최종값, 0.7초) → 감정 비율 막대 → 추이 격자 → 추이 선이 왼쪽에서 오른쪽으로 그려짐(`pathLength="1"` + `stroke-dashoffset`, 끊긴 구간은 시작 위치 `--x`만큼 늦게) → 면적·평균선·오늘 툴팁 → 날짜별 카드 점(`--i` 순서), 감정 분포 막대가 왼쪽부터 자람, 감정 달력 칸이 날짜순으로 자리 잡음, 요일 막대가 아래에서 차오름(모바일은 왼쪽부터).
- 재생 조건: 통계 진입, 월 이동, 시연/실제 모드 전환 때 1회. 같은 화면 재렌더(브레이크포인트 전환 등)와 카드 모달 열고 닫기에는 재생하지 않고, 다른 탭에 갔다 오면 다시 재생합니다. `statisticsPanel()`이 `mode:month` 키로 판단해 `.stats-page`에 `data-stats-anim="in"`을 붙이고, `render()`는 통계 밖 화면에서 키를 지웁니다.
- 스타일은 `styles/stats-motion.css`(`stats-*` 키프레임, `[data-stats-anim="in"]` 범위)이며 패널·막대 컨테이너는 위치를 옮기지 않고(opacity·clip-path만) 레이아웃 측정을 지킵니다. 앱 정책대로 움직임 줄이기 분기는 없습니다. 최종 숫자는 마크업(`data-count`)에 그대로 있습니다.
- 회귀 검사: `tests/stats-motion.cjs`. 테스트 도우미 `reveal(page,'review-month')`는 `settleStats()`로 연출이 끝날 때까지 기다립니다.

  - 분석된 카드는 모든 카드 표면(기록 카드·도감 슬롯·상세 창·배지·공유 미리보기·목록 썸네일·최근 기록 타일·미니카드)이 `data-emotion`(소분류 9종)을 가지며, 광채·버스트·입자 색은 그 감정의 카드 색(`--card-deep-*`·`--card-base-*`)을 씁니다. 출력은 `app.js` `gradeAttrs(card)` 하나로 모았습니다.

  - 예고(① 두근두근 · ② 고조)는 감정을 미리 드러내지 않도록 중립 파란빛으로 그리고, 등급이 높을수록 강해집니다(`--draw-power` 빈 .3 · 1단계 .5 · 2단계 .8 · 3단계 1, 박동 1.3/1.1/.9/.7초, 흔들림 0/1/3/5px). 고조 단계의 방사광은 2·3단계에만, 홀로그램 깜빡임은 3단계에만 나옵니다.
  - 펑(③, 1.7초 고정): 빈 카드는 회색 먼지 6개가 짧게 퍼지고 빛·링 없이 조용히 나타납니다. 1단계는 빛 번짐 + 입자 10 + 카드 광택 한 번, 2단계는 이중 링 + 입자 16 + 튀어 오름, 3단계는 방사광 + 홀로그램 링 + 감정 색 섬광 + 색종이 포함 입자 28 + 튀어 오름입니다.
  - 봉인 안내 문구는 "빛의 색은 감정, 공개 효과는 등급에 따라 달라요"이고, 범례는 효과 이름입니다: 빈 카드 잔잔한 먼지 · 1단계 은은한 빛 · 2단계 빛의 고리 · 3단계 홀로그램.

## 모바일 입력·홈 이동 호환성 (2026-11-23)

- 모바일(959px 이하)은 편집 가능한 텍스트 입력에 초점이 들어오면 하단 3탭을 숨기고 셸 하단 여백을 10px로 줄입니다. `textarea`, 텍스트·검색·이메일·URL·전화·비밀번호·숫자 `input`, `contenteditable`이 대상입니다. 읽기 전용·비활성 입력, 선택 상자·체크박스·라디오·버튼은 제외합니다.
- `app.js`가 초점 진입·이탈, 재렌더링, 창/페이지 복귀와 반응형 경계 전환에서 `html.mobile-input-active`를 동기화합니다. 입력 회차별로 축소 전 높이와 최소 높이를 보관하며, 줄어든 화면이 기준 높이에 가깝게 회복되면 입력 초점이 남아도 메뉴를 복구합니다. 시각 뷰포트만 또는 양쪽 뷰포트가 함께 변하는 환경과 `visualViewport` 미지원의 창 높이 변화에 대응합니다. 기종별 분기는 없습니다.
- 뒤로 가기/완료로 키보드를 닫으면 높이 회복 또는 지원되는 `VirtualKeyboard.geometrychange`의 닫힘 신호로 메뉴를 복구합니다. 같은 입력의 재렌더링·창 복귀가 메뉴를 다시 숨기지 않으며, 해당 입력을 다시 터치하거나 키보드 열림이 감지되면 재숨김합니다. 키보드가 열린 상태의 커서 이동 터치는 기존 높이 기준을 유지합니다.
- 확대 배율을 높이 계산에 반영하고, 폭 변경 시 기준을 재설정합니다. 작은 주소창 높이 변화는 키보드 닫힘으로 보지 않습니다(높이 변화 문턱: 120px와 기준 높이의 15% 중 큰 값). 데스크톱 상단 메뉴는 유지하고 강제 스크롤·초점 해제나 브라우저의 키보드 배치 설정 변경은 하지 않습니다. 높이 변화와 키보드 크기 이벤트가 모두 없는 환경은 입력 초점 기반 숨김/이탈 시 복구로 동작합니다.
- 상단 `moment`는 `button[data-action="write"]`이며 접근성 이름은 "기록 홈으로 이동", 터치 영역은 최소 44×44px입니다. 새로고침 없이 기록 홈으로 돌아가고 작성 초안을 보존합니다.
- S23 Ultra·삼성 인터넷이 수정 대상이며, 사용자가 정상 확인한 S24·iPhone 17 Pro 환경을 비교 기준으로 둡니다. 기종만으로 브라우저를 추정하지 않습니다. 자동 검사와 실기기 결과는 [QA](QA.md)의 같은 날짜 절에서 구분합니다.

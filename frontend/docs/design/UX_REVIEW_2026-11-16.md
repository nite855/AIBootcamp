# 까다로운 사용자 10인 UX 리뷰 (2026-11-16)

시뮬레이션 후기입니다. 실제 사용자 조사가 아니며, 비즈니스·기능 추가 비평은 범위에서 제외했습니다.

### 채운 명세
- 서비스명: 오늘의 모먼트 (한국어 일기·감정 카드)
- 환경: 모바일 반응형 웹 우선(320×568~390×844), PC 960px+ 
- 레이아웃: 좌측 "앱 이름+큰 화면 제목" 상단 바, 탭 5개(오늘·기록·돌아보기·도감·설정) — 960px+ 헤더 pill, 959px 이하 하단 고정 탭바. 오늘 화면 = 작성 에디터 + 최근/최신 기록 패널(±0.5° 기울임)
- 시각화: 돌아보기 = 감정 추이 곡선(Catmull-Rom+그라데이션+점선 격자+칩 범례), 월간 캘린더(`calendar-grid`), 감정 분포 막대(`distribution-row`), 월 요약/인사이트, 기록 검색·즐겨찾기 필터·페이지네이션, 30칸 캐릭터 도감, 플립 카드(1~3단계/빈 카드)
- 동선: 작성 → 저장(분석 대기) → 기록 목록 → 상세 플립 → 수정/삭제 재확인; 돌아보기 월 이동 → 날짜 클릭 → 날짜별 목록 → 상세
- 고민: 실제 기록이 전부 "분석 대기"라 대시보드가 빈 상태 위주, 예시 모드와 구분

## Part 1. 까다로운 사용자 10인 후기 (산출물에 그대로 수록)
1. **서지아 (24, 대학원생 / 정보 과부하 혐오)**
   - 돌아보기 첫 화면에 추이 그래프·월 요약·인사이트·캘린더·분포가 한 스크롤에 다 쏟아져서 뭘 먼저 봐야 할지 모르겠어요.
   - 오늘 화면에 에디터 옆으로 최근 기록·최신 기록 패널이 붙어 있어서 일기 쓰는 공간이 좁고 산만해요.
   - 월 요약 문장과 인사이트 문장이 같은 회색 톤이라 숫자 요약인지 해석인지 구분이 안 돼요.
2. **한유나 (29, 마케터 / 차트 울렁증)**
   - 추이 그래프 Y축이 "비중"인데 단위(%)도 기준선 설명도 없어서 곡선이 올라간 게 좋은 건지 모르겠어요.
   - 분석 없는 날 선이 뚝 끊기는데 그 이유가 그래프 안에 안 적혀 있어서 오류처럼 보여요.
   - 범례 칩이 10개 감정 색을 다 나열해서 선이 몇 개 안 되는 달엔 칩만 잔뜩 있어요.
3. **오채린 (32, PM / 클릭 수 집착)**
   - 캘린더 날짜 누르면 날짜별 목록, 또 눌러야 상세라 하루 한 편인 날도 두 번 들어가야 해요.
   - 상세에서 수정 → 저장 후 다시 목록 맨 위로 튕겨서 보던 위치를 잃어요.
   - 도감의 해제된 칸에서 연결 기록까지 가는 길이 칸→목록→카드 3단계예요.
4. **문소희 (27, 디자이너 / 폰트 크기·명도 대비 민감)**
   - 블라썸 크림 배경 위 `.muted` 회색 보조문구랑 11px 탭 라벨이 낮에 거의 안 읽혀요.
   - 추이 그래프 옅은 점선 격자와 그라데이션 영역이 배경과 대비가 낮아 값 위치를 못 잡겠어요.
   - 다크 모드에서 더스티 로즈 활성 탭 글자와 배경 대비가 애매해요.
5. **정다인 (35, 회계사 / 여백·정렬 강박)**
   - 최근·최신 패널을 일부러 0.5° 기울인 게 정렬 깨진 버그처럼 보여요.
   - 30px·pill 둥근 모서리, 26/34px 비대칭 모서리가 섞여서 컴포넌트마다 곡률이 제각각이에요.
   - 월 이동 버튼 "‹ 이전 달 / 다음 달 ›"과 월 라벨의 베이스라인·간격이 안 맞아요.
6. **강하린 (23, 학생 / 모호한 아이콘·라벨 극혐)**
   - 탭 이름 "돌아보기"랑 "기록"이 둘 다 과거 기록 같아서 어디서 통계를 보는지 헷갈려요.
   - "분석 대기"가 언제 끝나는지, 내가 뭘 해야 하는지 문구가 하나도 없어요.
   - 상단 바의 보관함 상자 아이콘과 하단 "기록" 탭이 같은 곳인지 다른 곳인지 모르겠어요.
7. **윤세아 (30, 데이터 분석가 / 필터·정렬 탐색 집착)**
   - 기록 검색에 정렬(최신/오래된)이 없고 필터는 "즐겨찾기만" 하나라 감정·단계로 못 좁혀요.
   - 필터 적용 중인지 상단에 칩으로 안 보여서 결과가 적을 때 필터 때문인지 모르겠어요.
   - 돌아보기 월 이동이 이전/다음 버튼뿐이라 3달 전으로 가려면 세 번 눌러야 해요.
8. **배수빈 (26, 간호사 / 시각적 피로도 민감)**
   - 배경 방사형 그라데이션 두 겹에 패널 그림자까지 겹쳐서 밤에 화면이 뿌옇게 번져 보여요.
   - 새 카드 배지의 반짝이 12개+광택+스프링이 한꺼번에 터져서 눈이 피곤해요.
   - 카드 열 때마다 떠오르는 0.42초 모션이 연속으로 넘길 때 계속 반복돼요.
9. **임가은 (28, 개발자 / 반응형 깨짐 민감)**
   - 320px 폭에서 큰 화면 제목이 nowrap이라 "돌아보기" 옆 공간이 빠듯하고 잘릴 듯해요.
   - 키 낮은 폰(≤700px)에서 최신 기록 패널이 아예 사라져서 화면마다 구성이 달라요.
   - 하단 탭바가 키보드 올라올 때 에디터를 가리는지 확인이 안 돼요.
10. **송예린 (33, UX 리서처 / 로딩·호버 피드백 중시)**
   - 저장 버튼 누른 뒤 저장 중 상태가 버튼에만 잠깐 보이고 완료 토스트가 없어요.
   - 추이 점 호버 툴팁은 마우스 전용이라 모바일에선 값 확인 방법이 없어요.
   - 캘린더 날짜 칸이 hover·focus 때 모양 변화가 약해서 눌리는 칸인지 모르겠어요.

| 1순위 | 마이크로카피 | "분석 대기"·탭명 모호(6) | 대기 사유 한 줄 안내("감정 분석 연결 준비 중, 기록은 안전하게 보관됨"), 탭 "돌아보기"→"통계" 검토 후 확정(질문 필요 시 구현 직전 확인), 상단 보관함 아이콘과 기록 탭 중복 정리 |

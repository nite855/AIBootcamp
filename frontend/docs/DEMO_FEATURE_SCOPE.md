# 오늘의 모먼트 시연 기능 범위

[5분 시연 시나리오](DEMO_SCENARIO.md)를 기준으로 발표에서 직접 보여줄 기능과 생략할 기능을 정리한다. 시연의 네 축은 **기록·카드·공유·통계**이며, 실제 기록 저장 → 예시 카드 공개 → SNS 공유 → 감정 통계 순서로 진행한다. 도감은 카드의 보조 기능으로 소개한다.

- 기준일: 2026-11-24(`38fbebb`)
- 기본 시연 시간: 약 5분
- 적용 화면: 현재 메인 프론트엔드
- 로그인은 준비되어 있다고 가정한다. 실제 인증이나 계정 기반 저장이 구현되었다는 의미는 아니다.

## 1. 구분 기준

| 구분 | 의미 |
| --- | --- |
| 시연 포함 | 기본 5분 흐름에서 직접 조작하거나 결과를 설명한다. |
| 시연 생략 | 현재 기능은 있으나 기본 흐름에서 조작·검증하지 않는다. 화면에 버튼이나 옵션이 보여도 기능을 시연한 것으로 보지 않는다. |
| 선택 시연 | 기본 흐름에서는 생략하며 시간 여유나 질문이 있을 때 추가한다. |
| 가정 또는 미연결 | 구현 완료 기능으로 소개하지 않는다. 화면 진입을 가정하거나 현재 한계를 설명한다. |

기록 입력과 저장은 실제 데이터로 보여준다. 카드 공개·도감·감정 통계·공유는 기존 시연 모드의 합성 예시를 사용하며, 방금 작성한 글의 분석 결과와 구분한다.

## 2. 시연의 네 가지 핵심 기능

| 핵심 | 관객에게 보여줄 가치 | 필수 시연 범위 |
| --- | --- | --- |
| 기록 | 하루의 경험을 글로 남긴다. | 입력 → 실제 저장 → 분석 대기 확인 |
| 카드 | 기록을 시각적인 감정 카드로 만난다. | 예시 카드 자동 공개 → 감정·단계 확인 → 도감 보관 방식 소개 |
| 공유 | 남기고 싶은 감정 카드를 SNS로 전달한다. | 공유 미리보기 → 인용 공개 범위 선택 → PNG 저장 → 스토리용 이미지와 기기 공유 또는 저장 |
| 통계 | 쌓인 기록에서 감정 흐름을 돌아본다. | 월간 요약 → 긍정 추이 → 감정 분포 → 감정 달력 |

로그인·탭 이동·프로필의 시연 모드 전환은 위 네 기능을 연결하는 준비 동작이다. 별도의 핵심 기능 소개 시간은 배정하지 않는다.

## 3. 시연에서 보여줄 세부 기능

| 번호 | 기능 | 보여줄 조작 또는 결과 | 데이터 및 설명 범위 |
| --- | --- | --- | --- |
| S01 | 로그인 화면에서 기록 화면으로 진입 | 준비된 로그인 화면 또는 시안에서 기록 화면으로 넘어간다. | 가정한 흐름이다. 실제 인증 성공이나 계정 동기화를 검증하는 단계가 아니다. |
| S02 | 기록·통계·도감 탐색 | 세 탭의 위치를 소개하고 시연 순서에 따라 이동한다. | 한 가지 발표 환경을 사용한다. 모바일이면 하단 탭을 소개한다. |
| S03 | 하루 기록 작성 | 준비한 예시 글을 입력한다. | 실제 입력이다. 하루 한 편 기록이라는 이용 규칙을 설명한다. |
| S04 | 기록 저장과 분석 대기 | ‘기록하고 카드 받기’를 누르고 저장 후 대기 안내를 확인한다. | 브라우저 IndexedDB에 실제 저장된다. 모바일 버튼은 ‘카드 받기’다. 분석 완료 결과는 나오지 않는다. 당일 기록이 있으면 버튼이 ‘수정한 내용 저장하기’ 또는 ‘오늘 기록 바꾸기’(확인창)로 바뀐다. |
| S05 | 시연 모드 전환 | 프로필을 열고 ‘시연 모드’를 켜고 카드 획득 팝업을 닫은 뒤 예시 기록 목록으로 이동한다. 대안: 분석 대기 패널 → ‘도감 보기’ → ‘시연 모드로 미리 보기’(도감에 머묾). | 실제 기록과 분리된 합성 예시임을 알린다. 프로필의 다른 설정은 조작하지 않는다. |
| S06 | 감정 카드 자동 공개 | 분석 완료 예시 기록을 열고 공개 연출과 결과 카드를 보여준다. | 예시 감정 이름·단계·효과를 소개한다(색은 감정, 테두리·재질은 단계). ‘건너뛰기’는 누르지 않고 끝까지 재생한다. 실제 입력의 실시간 AI 분석이라고 설명하지 않는다. |
| S07 | 카드의 도감 보관 방식 | ‘도감에서 보기’로 상세를 열고 연결 기록·단계 안내를 짧게 보여준다. | 카드의 보조 기능이다. 총 27칸이며, 기존 예시 도감이므로 새 수집 수 증가를 약속하지 않는다. |
| S08 | 공유 미리보기와 인용 선택 | 이어서 ‘공유하기’를 열고 인용 문장을 껐다 켠다. | 첫 문장 최대 40자와 인용 제외 동작을 보여준다. 나머지 본문은 이미지에 포함되지 않는다. ‘분석 확률 표시’는 기본값(꺼짐)으로 둔다. |
| S09 | 공유 이미지 저장 | ‘이미지로 저장’을 누르고 내려받은 PNG를 연다. | 1080×1350 이미지다. 예시 카드의 공유 결과를 확인한다. |
| S10 | SNS 스토리 공유 | ‘인스타그램 스토리로 공유’를 눌러 기기 공유 창 또는 스토리 이미지 저장을 보여준다. | 1080×1920 이미지다. 지원 기기는 공유 창에서 SNS 앱을 선택하는 흐름으로, 미지원 환경은 저장한 이미지를 SNS에 올리는 흐름으로 설명한다. 자동 게시가 아니다. |
| S11 | 월간 통계 요약 | 공유를 마친 뒤 통계 탭에서 예시 기록이 있는 월을 선택하고 요약 카드를 보여준다. | 합성 예시 기록을 집계한 화면이다. |
| S12 | 감정 추이와 분포 | 긍정 추이, 감정 분포, 감정 달력을 차례로 짚는다. | 긍정 추이는 3일 이동평균이다. 심리 진단이나 미래 예측으로 소개하지 않는다. |
| S13 | 최근 기록과 카드 달력 | 마지막에 기록 탭으로 돌아와 최근 기록과 카드 달력을 보여준다. | 시연 모드 화면이다. 목록·달력의 구성만 소개하며 모든 탐색 동작은 수행하지 않는다. |

## 4. 기본 시연에서 보여주지 않는 기능

아래 기능은 현재 메인 프론트엔드에 있지만, 기본 시연에서는 생략한다. 설정 화면이나 메뉴가 잠시 보이더라도 변경 동작까지 진행하지 않는다.

| 번호 | 기능 | 생략할 조작 또는 검증 | 생략 이유 |
| --- | --- | --- | --- |
| N01 | 과거 기록 검색과 필터 | 본문 검색, 날짜·감정 조건, 최신·오래된 순 정렬, 페이지 이동 | 핵심 기록 흐름에 집중한다. 예시 목록 진입은 보여주되 검색 과정은 생략한다. |
| N02 | 즐겨찾기 | 지정·해제, 즐겨찾기만 모아 보기 | 보관 편의 기능으로 질의응답 때 추가할 수 있다. |
| N03 | 기록 본문 전체 읽기 | ‘기록 읽기’로 전문을 열고 스크롤하기 | 연결 기록의 존재만 소개하고 카드 경험에 집중한다. |
| N04 | 기록 수정 | 기존 본문 수정 후 재저장 | 신규 작성 흐름을 기본으로 한다. 당일 기록이 이미 있는 반복 시연에서만 대체한다. |
| N05 | 기록 삭제와 되돌리기 | 개별 삭제, 삭제 확인, 되돌리기, 전체 기록 삭제 | 발표 중 시연 데이터를 바꾸는 작업을 줄인다. |
| N06 | 초안 관리와 작성 도움 | 입력을 멈춘 뒤 초안 저장 확인, 새로고침 복원, ‘무엇을 쓸까요?’, 초안 지우기 | 입력 중 초안 저장은 동작할 수 있으나 별도 기능으로 시연하지 않는다. |
| N07 | 저장 오류 대응 | 실패 원인 보기, ‘다시 시도’, 다른 탭 저장 충돌 확인 | 정상 저장을 기본으로 한다. 오류가 실제 발생했을 때만 대응한다. |
| N08 | 카드 달력 상세 탐색 | 주간·월간 전환, 여러 주·월 이동, 날짜 선택과 카드 모달 열기 | 달력의 모습은 S13에서 보여주고 상세 탐색은 생략한다. 통계 화면의 월 선택은 S11에 포함한다. |
| N09 | 테마 변경 | 10종 테마 선택과 장식 비교 | 발표 전 한 가지 테마로 고정한다. |
| N10 | 프로필 편집 | 닉네임·아바타 색·아이콘 변경 | 프로필은 시연 모드 전환에만 사용한다. |
| N11 | 알림 설정 저장 | 기록 알림·분석 완료 알림 스위치 변경 | 설정 저장만 가능하며 실제 알림은 발송하지 않는다. 두 스위치에 ‘준비 중’ 표시가 있다. |
| N12 | 공유 세부 설정 | 카드 중심·기록 중심·카드+기록 형식 전환, 인용 문장 직접 편집, 날짜·감정 이름·‘분석 확률 표시’ 변경 | 기본 공유 형식에서 인용 표시 전환·PNG 저장·SNS 스토리 공유에 집중한다. |
| N13 | 앱 주소 복사 | ‘앱 주소 복사’를 눌러 클립보드에 저장 | 현재 복사 대상은 앱 주소다. 개별 카드 열람 링크 기능은 없다. |
| N14 | 카드 상태와 효과 비교 | 빈 카드·분석 실패 예시 열기, 여러 단계·등급 효과 비교, 별도 카드 획득 팝업 유도 | 분석 완료 예시 한 편으로 대표 경험을 보여준다. |
| N15 | 앱 정보와 글꼴 라이선스 | 설정의 라이선스 창 열기 | 발표의 핵심 이용 흐름에서 제외한다. |
| N16 | 여러 기기 화면 비교 | 데스크톱·모바일 동시 비교, 키보드 열기·닫기 회귀 확인 | 한 가지 발표 환경에서 진행한다. 모바일로 발표하면 입력과 키보드는 자연스럽게 보일 수 있다. |
| N17 | 도감 전체 탐색 | 긍정·부정·중립 탭 비교, 여러 카드·단계의 연결 기록 탐색 | 기본 시연은 카드 한 편의 보관 방식만 보여주고 공유로 이어 간다. |
| N18 | 공개 연출 건너뛰기와 움직임 줄이기 | ‘건너뛰기’·‘바로 보기’·Esc, OS 동작 줄이기에서의 정지 대체 연출 | 기본 시연은 연출을 끝까지 보여준다. 질문이 나오면 기능 존재만 설명한다. |

### 시간 여유가 있을 때만 보여줄 기능

| 번호 | 기능 | 추가 시연 범위 | 주의할 설명 |
| --- | --- | --- | --- |
| O01 | 요일별 마음 | 통계 아래쪽의 요일별 집계와 안내를 보여준다. | 합성 예시의 관찰 결과로 소개한다. |

## 5. 구현 완료 기능으로 보여주지 않는 항목

이 항목들은 단순히 발표 시간 때문에 생략하는 기능과 다르다. 로그인 진입 가정과 현재 연결 상태를 설명할 때만 언급한다.

| 번호 | 항목 | 현재 상태 | 발표에서 사용할 설명 |
| --- | --- | --- | --- |
| U01 | 실제 인증과 계정 관리 | 로그인은 시나리오의 가정이다. 회원가입·로그아웃·비밀번호 재설정 등을 검증하는 시연은 준비하지 않는다. | “로그인 화면이 준비되어 있다는 가정으로 진입 흐름을 보여드립니다.” |
| U02 | 실제 기록의 새 감정 모델 분석 | 프론트의 3+9 감정 체계와 실제 모델 연결 전이다. 실제 기록은 분석 대기로 저장된다. | “작성과 저장은 실제 동작이며, 이어지는 카드 결과는 합성 예시입니다.” |
| U03 | 분석 완료 알림과 예약 알림 발송 | 프로필에서 설정만 저장한다. 실제 알림은 보내지 않는다. | “알림 설정 화면은 있으나 발송 기능은 연결 전입니다.” |
| U04 | 계정별 서버 저장과 기기 간 동기화 | 현재 기록은 브라우저별 IndexedDB에 보관한다. 계정 동기화·서버 백업은 없다. | “다른 기기에서 같은 기록이 자동으로 이어지지는 않습니다.” |
| U05 | 개별 카드 공개 링크 | ‘앱 주소 복사’는 앱 주소만 복사한다(화면에 “받는 사람에게 내 카드나 기록은 보이지 않아요” 안내). 서버에 카드별 공유 페이지를 생성하지 않는다. | “이미지 공유는 가능하며, 카드별 열람 링크는 제공하지 않습니다.” |
| U06 | 현재 프로필의 기록 내보내기 | 프로필에는 기록 내보내기 메뉴가 없다. 공유 PNG 저장과 기록 데이터 내보내기를 구분한다. | “이번에 보여드리는 저장은 카드 이미지 저장입니다.” |
| U07 | 인스타그램 자동 게시 | 기기 공유 창이나 스토리 이미지 저장까지 지원한다. 자동 게시는 제공하지 않는다. | “스토리 이미지를 공유하거나 저장한 뒤 사용자가 게시합니다.” |

## 6. 발표자 확인표

- [ ] 로그인은 가정한 흐름이며, 인증·동기화 완료를 주장하지 않는다.
- [ ] 실제 저장 후 분석 대기 안내를 보여주고 예시 모드 전환을 알린다.
- [ ] 기록·카드·공유·통계 순서로 S01~S13을 진행한다.
- [ ] SNS 스토리 공유 S10은 핵심 시연에 포함하고, 기기 공유 미지원 환경에서도 스토리 이미지 저장 결과를 보여준다.
- [ ] N01~N18은 기본 흐름에서 조작하지 않고, O01은 시간 여유가 있을 때만 추가한다.
- [ ] 감정 분류 확률을 감정 강도나 모델 전체 정확도로 설명하지 않는다.
- [ ] 공유할 인용 문장과 이미지 결과를 확인한다.
- [ ] 시연에서 생략한 기능과 현재 미연결 기능을 구분해 답변한다.

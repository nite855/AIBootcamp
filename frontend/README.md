## 실행과 보관

`index.html` 하나를 브라우저에서 엽니다. 실제 기록·초안·기록 방식은 메인 전용 IndexedDB `moment-diary-main`에 보관하며 새로고침 후 복원합니다. 표시 설정은 기존 localStorage 키를 유지합니다. 복원 중에는 입력과 변경을 잠시 비활성화합니다. 브라우저 데이터 삭제 시 기록도 사라지며, 파일 URL과 서버 URL은 같은 저장소를 공유한다고 보장하지 않습니다. 계정·동기화·서버 백업과 실제 분석은 연결하지 않았습니다. 화면 구성은 아래 2026-11-14 절을 기준으로 합니다.

설정의 하루 한 편은 오늘 기록을 갱신하고, 여러 편은 새 기록 쓰기마다 항목을 생성합니다. 기록 날짜는 현지 날짜로 자동 결정하며 기존 기록 수정은 원래 날짜를 유지합니다.

## 기록별 카드

기록 ID와 원문 버전으로 분석·카드를 연결합니다. 실제 글은 현재 분석 대기 상태입니다. 설정의 예시 모드에서만 분석된 예시 카드와 수집을 확인할 수 있습니다. 예시 데이터는 실제 기록과 섞이지 않습니다.

10개 감정 중 최다 확률을 반올림 전에 판정합니다. 30% 미만은 빈 카드, 30% 이상~60% 미만은 1단계, 60% 이상~90% 미만은 2단계, 90% 이상은 3단계입니다. 동률은 기존 감정 ID 순서로 대표를 선택하고 공동 최다 표시를 남깁니다. 분석 실패·대기는 빈 카드와 구분합니다. 단계는 감정 강도나 성장 점수가 아닙니다.

같은 캐릭터여도 기록별로 독립된 카드이며 날짜·작성 시각을 표시합니다. 선택한 기록의 카드를 1080×1620 PNG로 저장하며 원문은 포함하지 않습니다. 기존 3D PNG 7종에 중립 소분류 4종의 SVG 표식과 단계 배지를 결합해 10종을 표현합니다. 분석 대기·실패·빈 카드에는 감정 캐릭터를 표시하지 않습니다. 카드 앞면을 탭하면 원문을 읽고, ‘기록 읽기’로 긴 원문을 확대할 수 있습니다. 카드 효과는 기본 켜짐이며 설정의 버튼 하나로 켜고 끕니다. 모바일에서는 본문 밖을 터치하면 즉시 빛과 기울기가 표시되고, 드래그하면 손가락을 따라 움직입니다. 손을 떼면 원상 복귀하며 드래그·길게 누르기는 카드를 뒤집지 않습니다.

## 보관함

- 지난 기록: 날짜·작성 시각·카드 상태를 확인하고 기록과 카드를 열어봅니다.
- 돌아보기: 감정 추이·월간 기록·감정 분포를 한 화면에서 전환합니다. 분석 누락을 중립으로 채우지 않습니다.
- 캐릭터 도감: 10유형 × 3단계의 30개 슬롯입니다. 만난 단계만 해제합니다. 같은 슬롯의 마지막 기록을 삭제하거나 수정해 분석이 무효화되면 다시 잠깁니다.

원문 수정은 버전을 증가시키고 분석을 대기로 바꿉니다. 이전 버전 분석은 카드·통계·도감에서 제외합니다. 캐릭터 도감에서 해당 유형·단계의 기록으로 이동할 수 있습니다.

## 화면 테마

설정에서 Lemon & Cocoa, 페이퍼 다이어리, 세이지 터치, 리퀴드 오로라, 에디토리얼 모노, 레트로 플레이, 숲속 쉼터, 노을 산책, 별빛 밤을 선택합니다. 갤러리에서 썸네일을 누르고 미리보기의 적용 버튼으로 확정합니다. 각 테마는 밝음·어두움·시스템 모드를 지원합니다. 저장된 선택이 없거나 유효하지 않을 때 기본값은 Lemon & Cocoa + 밝음입니다. 기존 사용자의 선택은 유지합니다. 선택은 앱 전체와 카드 PNG(1080×1620)에 적용됩니다. 저장소 차단 시 현재 실행에만 적용합니다. 표시 설정과 일기 저장소는 분리되어 있습니다.

테마 검증: `node tests/themes.cjs`. 기존 브라우저 검사와 같은 Playwright·Chrome 경로를 사용합니다.

## 영구 저장과 삭제

초안은 입력 후 500ms, 기록 확정·수정·삭제와 기록 방식은 즉시 저장합니다. 실제 기록은 최대 30편, 기록 또는 초안 하나는 최대 10,000자입니다. ‘초안 저장됨’은 트랜잭션 완료 후 표시합니다. 예시 데이터와 화면 탐색 상태는 저장하지 않습니다.

저장 실패 시 화면의 내용을 유지하며 ‘저장 재시도’를 제공합니다. 다른 탭이 먼저 저장한 경우 덮어쓰기를 중단하므로 현재 내용을 복사한 뒤 새로고침하세요. 저장소 접근 실패나 손상된 데이터가 있어도 메모리에서 작성할 수 있지만 저장 성공으로 표시하지 않습니다. 미저장 변경에는 이탈 경고를 표시합니다.

작성 화면의 ‘초안 지우기’는 초안만, 설정의 ‘이 브라우저의 기록 전체 삭제’는 실제 기록과 초안을 삭제합니다. 두 동작 모두 두 번 확인하며 테마 설정과 예시 데이터는 유지합니다. 기존 Flip 시안의 저장소를 가져오거나 삭제하지 않습니다.

## 3+10 감정 체계 (2026-11-10)

긍정은 기쁨·활력, 만족·감사, 안정·자신감입니다. 부정은 불안, 슬픔, 분노이며 중립은 객관적 서술, 의문, 놀람, 당황입니다. 카드 배지는 대표 소분류의 소속 대분류를 표시하고, 통계는 소분류 확률을 합산해 대분류 비중을 표시합니다. 두 대표값은 서로 다를 수 있습니다.

도감은 30슬롯입니다. 중립 4종은 기존 중립 PNG에 문서·물음표·느낌표·물음표와 느낌표 표식을 조합하며 이미지 저장에도 적용합니다. 분류 확률은 감정 강도나 모델 정확도가 아닙니다. 30·60·90% 기준은 기존 UI 정책이며 새 모델에 대한 검증 결과가 아닙니다.

예시 65편은 30슬롯을 두 번씩 포함하고 빈 카드·대기·실패·동률·이전 기록 버전 상태를 제공합니다. 실제 기록과 초안의 저장 방식은 유지하고 실제 분석은 연결하지 않습니다. [후속 분석 연동 계약](docs/API_CONTRACT.md)을 참고하세요.

추가 회귀 검증: `node tests/taxonomy-browser.cjs`.


## 메인 기능 통합 (2026-11-11)

Docker의 기록 중심 시안 기능을 메인에 적용했습니다. 상단은 오늘 쓰기·지난 기록·돌아보기·설정이며, 작성 도움말은 원문을 변경하지 않습니다. 지난 기록은 본문 검색·날짜·즐겨찾기 조건을 함께 적용하고 페이지당 6편을 표시합니다. 돌아보기의 월간 캘린더에서 날짜별 기록을 열 수 있습니다.

작성은 한 열이며 저장 결과는 960px 이상에서 작성창·카드 3:2, 그 미만에서는 카드 중심 한 열입니다. 문서 스크롤을 허용하고 카드 효과는 앱의 켜짐/꺼짐 선택을 우선하며, 켜짐이면 OS의 움직임 줄이기 설정과 관계없이 적용합니다. 기존 와이어프레임은 이전 화면의 참고 자료이며 현재 배치는 이 명세와 앱을 기준으로 합니다.

저장소는 기존 `moment-diary-main`, 표시 설정은 `moment-card:diary-simple-v3:`를 유지합니다. 기존 기록의 누락된 `favorite`은 false로 읽습니다. 기록 수정 시 즐겨찾기를 보존합니다. 실제 분석은 계속 대기 상태입니다.

설정 → 데이터 관리에서 실제 기록·즐겨찾기를 JSON으로 내보내고 가져옵니다. 시안과 동일한 `moment-benchmark-backup` 버전 1 형식이며 초안·예시·분석·테마는 제외합니다. 파일은 5MiB, 기록당 10,000자, 합산 30편까지입니다. 동일 ID·동일 내용은 건너뛰고 충돌 또는 용량 초과는 전체 병합을 차단합니다. 저장 완료 후에만 병합 결과를 반영하며 기존 초안을 유지합니다.

시안에서 내보낸 파일을 메인에서 선택하고 추가·동일·충돌 건수를 확인한 뒤 합치세요. 주소·브라우저·기기별 저장소는 별개입니다. 시안 저장소를 자동으로 읽거나 삭제하지 않습니다. 현재 Docker 미리보기는 유지되며 메인 빌드로 교체 배포하려면 기존 Docker 실행 절차를 사용합니다.

추가 검증: `node tests/benchmark-browser.cjs`, `node tests/compatibility-browser.cjs`. LAN HTTP는 `MOMENT_LAN_URL`에 메인 실행 주소를 지정하고 `node tests/mobile-lan.cjs`로 검사합니다. 실기기 Safari·키보드는 별도 확인이 필요합니다.

## 기록 요약과 테마 갤러리 (2026-11-14)

첫 화면은 PC에서 작성·요약 3:2, 모바일에서 작성 → 최신 카드 상태 → 최근 기록 순서입니다. 최근 기록은 날짜와 작성 시각 내림차순 최대 3편입니다. 상단은 오늘·기록·메뉴이며 돌아보기·캐릭터 도감·설정은 메뉴에서 엽니다. 저장 후 작성 화면을 유지하고 요약을 갱신합니다. 기본 버튼은 5개, 최근 기록이 있을 때 최대 8개입니다. 작성 도움말과 초안 지우기는 작성 옵션에서 엽니다.

설정 → 화면 테마에서 9개 테마를 PC 3열·모바일 2열로 비교합니다. 썸네일을 누르면 합성 예시 화면으로 큰 미리보기를 열며, 화면 모드는 밝음·어두움·시스템 중 선택합니다. 미리보기와 모드 변경은 임시 선택이며 ‘이 테마 적용’을 눌러야 함께 저장합니다. 닫기·Esc·설정으로 돌아가기는 기존 선택을 유지합니다. 적용 후에도 작성 중인 초안은 유지합니다.

기존 6종에 숲속 쉼터(`forest`)·노을 산책(`sunset`)·별빛 밤(`starlight`)을 추가했습니다. 그림은 `assets/themes/`의 프로젝트 원본 SVG이며 빌드 결과에 내장합니다. 카드 PNG는 기존 1080×1620 프레임·캐릭터와 선택한 팔레트를 유지합니다. 기본값·설정 키·IndexedDB 형식은 동일합니다. 실제 감정 분석은 계속 준비 중입니다.
